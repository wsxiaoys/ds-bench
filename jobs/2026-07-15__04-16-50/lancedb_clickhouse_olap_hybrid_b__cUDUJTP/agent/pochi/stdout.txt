### Solution Overview

1. **Deterministic Query Embedding**:
   - The query text is lowercased, and tokens are extracted using the regex `[a-z0-9]+`.
   - A 32-dimensional `float32` vector is built by hashing each token with MD5, taking the modulo 32 to find the index, and adding `1.0` to that index.
   - The final vector is L2-normalized.

2. **Recall (LanceDB FTS)**:
   - Candidates are queried using LanceDB's full-text search (FTS) index on the `text` column of the `documents` table with a sufficiently large limit to capture all potential matches.

3. **Vector Distance (LanceDB)**:
   - For all retrieved candidate document IDs, we perform a vector search with the embedded query vector, filtering the search space to the candidate IDs using a `where` clause to retrieve the exact L2 distance (`_distance`).

4. **Enrichment (ClickHouse)**:
   - Using a single batched query, we retrieve behavioral metrics from the local ClickHouse server for the candidate `doc_id`s within the specified half-open time window (`ts >= window_start AND ts < window_end`).
   - The query computes:
     - `events_in_window`: total count of events.
     - `premium_value_sum`: conditional sum of `value` where the user tier is `'premium'` (joined on `users`).
     - `p95_value`: 95th percentile of `value` using ClickHouse's exact quantile function `quantileExact(0.95)`.
     - `peak_hour_count`: maximum hourly event count, bucketed by `toStartOfHour(ts)`.

5. **Fusion, Scoring & Sorting**:
   - Candidate documents not present in the ClickHouse results are automatically back-filled with `0` or `0.0` for all numeric fields.
   - The hybrid score is computed as `score = premium_value_sum / (1.0 + vector_distance)`, rounded to 6 decimal places.
   - Output results are sorted by `score` descending, with ties broken by `doc_id` ascending, limited to the top `top` elements.

6. **CLI Implementation**:
   - The CLI is located at `/home/user/hybrid_bridge/run.py` and can be run with:
     ```bash
     python3 run.py --query-file <path/to/query.json> --output <path/to/result.json>
     ```
   - It is fully tested, robust, and correctly maps all JSON values to native Python/JSON types (preventing numpy serialization issues).
