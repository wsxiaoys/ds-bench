def compute_embedding(text: str) -> list:
    text_lower = text.lower()
    tokens = re.findall(r'[a-z0-9]+', text_lower)
    vector = np.zeros(64, dtype=np.float32)
    for token in tokens:
        idx = int(hashlib.md5(token.encode('utf-8')).hexdigest(), 16) % 64
        vector[idx] += 1.0
    norm = np.linalg.norm(vector)

### Implementation Details

1. **Broker Topology Declaration**:
   - The script idempotently declares the direct dead-letter exchange `documents.dlx` (type `fanout`, durable).
   - It declares the main queue `documents` (durable, arguments `{"x-queue-type": "quorum", "x-dead-letter-exchange": "documents.dlx"}`).
   - It declares the dead-letter queue `documents.dlq` (durable, arguments `{"x-queue-type": "quorum"}`) and binds it to `documents.dlx`.

2. **Deduplication and Manual Acknowledgement**:
   - Messages are consumed using manual acknowledgement with `basic_get` in a loop, ensuring the script drains all currently-available messages and exits immediately.
   - To achieve *effectively-once* storage, the script checks if a document ID has already been written to LanceDB (by querying the table) or is currently buffered/committed in the current run using an in-run seen-set.
   - A message is only acknowledged (`basic_ack`) after the batch containing it has been durably written to LanceDB and logged. For duplicate messages, they are acknowledged immediately if already written in a prior batch/run, or grouped and acknowledged with the active batch if they duplicate a document currently in the buffer.

3. **Poison Message Handling**:
   - The script validates the message payload format (UTF-8 decoded JSON, object type, non-empty string `id`, and non-empty string `text`).
   - If a message is malformed or invalid, it is immediately rejected without requeue (`basic_nack(requeue=False)`), routing it to the dead-letter queue via the dead-letter exchange, and the worker continues without crashing.

4. **Deterministic Local Embedding (64-dim float32)**:
   - Implemented exactly according to the requirements: lowercases text, extracts alphanumeric tokens matching `[a-z0-9]+`, hashes each token using MD5 to map to a 64-length zero vector, and performs L2-normalization on the final vector.
