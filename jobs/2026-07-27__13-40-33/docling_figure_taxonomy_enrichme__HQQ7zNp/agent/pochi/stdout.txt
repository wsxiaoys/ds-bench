## What it does
1. **Converts** `assets/report.pdf` with Docling's `StandardPdfPipeline` using `PdfPipelineOptions` with picture/figure **classification enrichment enabled** (`do_picture_classification=True`), `generate_picture_images=True`, `generate_page_images=True`, and `images_scale=2.0`. It runs strictly offline (`HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`, `enable_remote_services=False`, `artifacts_path` pointed at the locally cached `DocumentFigureClassifier-v2.5` weights).
2. **Iterates pictures in document reading order** (`doc.iterate_items(traverse_pictures=True)`), and for each picture records:
   - `class_label` + `confidence` from the top (highest-confidence) prediction stored in `picture.meta.classification.predictions` (with a legacy `annotations` fallback).
   - `page_no` (1-based, from provenance).
   - normalized `bbox` (`x0<x1`, `y0<y1`, min/max corners, clamped to `[0,1]`) via `bbox.normalized(page_size)`.
   - `caption` via `picture.caption_text(doc)` (empty string when none).
   - `image_path` of the cropped PNG saved from `picture.get_image(doc)` rendered at scale 2.0.
3. **Writes** exactly the required artifacts:
   - `output/taxonomy_report.json` — single JSON object with keys `source_pdf`, `figure_count`, `figures` (keyed `"0".."N-1"`, each entry with exactly the six required keys).
   - `output/taxonomy_summary.md` — Markdown grouping figures by predicted class label (verbatim), referencing every figure index `0..N-1`.
   - `output/figures/figure_*.png` — cropped picture PNGs.
