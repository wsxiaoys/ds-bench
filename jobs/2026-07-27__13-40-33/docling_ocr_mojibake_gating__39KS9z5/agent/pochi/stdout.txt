# Two-Pass OCR Gating Pipeline for Docling ## Background Docling (`docling` v2.107.0, already installed in this offline container) extracts a PDF's embedded programmatic text layer by default and only falls back to optical character recognition (OCR) for pages it recognizes as bitmap scans. This produces two failure modes for real-world documents: (a) pages that are image-only scans yield little or no usable text from the programmatic layer, and (b) pages with broken/non-standard font encodings emit corrupted "mojibake" text. A robust ingestion pipeline must therefore *detect* per-page text corruption and selectively repair only the affected pages with OCR, while leaving clean pages untouched. You must build a command-line pipeline that performs exactly this two-pass "OCR gating" over a fixed input PDF and emits a repaired Markdown document plus a machine-readable gating report. The environment is fully offline: all model weights and the Tesseract engine are pre-baked into the image.
