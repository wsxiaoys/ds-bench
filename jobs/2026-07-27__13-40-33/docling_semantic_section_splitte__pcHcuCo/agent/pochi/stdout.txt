## How it works
1. **Parse** with `docling.document_converter.DocumentConverter` and iterate `DoclingDocument.iterate_items()` in reading order. Each item's page number comes from `item.prov[0].page_no`.
2. **Classify** each item deterministically from the text (not the model-predicted level, which is flat `##` for everything):
   - Section heading ⇔ heading-like label (`section_header`/`title`) **and** text matches `^\d+(\.\d+){0,2}\s`. Level = count of dot-separated integers in the outline number (1/2/3).
   - The single heading-like item without an outline number is the document **title**.
   - Everything else is **body** belonging to the most recent heading (hence to its enclosing H1 section).
3. **Render** one file per H1 under `output/sections/` as `<NN>-<slug>.md`, starting with `# <full H1 text>`, followed by an `Index`/`Previous`/`Next` nav line, then descendant headings (`##`/`###`) and body text in reading order. Body items are kept as `Heading` objects so page numbers propagate.
4. **`output/index.md`** lists one link per H1 (`[<full text>](sections/<NN>-<slug>.md)`).
5. **`output/toc.json`** holds `title` and a nested `sections` tree built with a level-indexed stack (L2 parented under preceding L1, L3 under preceding L2). Each node has `title`, `level`, `anchor` (slug), `page_no`, `children`; `filename` appears **only** on level-1 nodes.
