## What was built

### `build_chart.py` — key design decisions

| Requirement | Implementation |
|---|---|
| Read local CSV only | `pd.read_csv("metrics.csv", parse_dates=["date"])` — no remote URLs |
| 2-column wrapped facet | `.facet(facet=Facet("series:N"), columns=2)` on the outer chart |
| Independent y-axis per panel | `.resolve_scale(y="independent", color="shared")` on the faceted chart |
| Shared color scale + single legend | `color="shared"` in resolve; color encoded once on the base, propagated to all layers |
| Single shared hover interaction | `alt.selection_point(on="pointerover", nearest=True, fields=["date"])` added via `add_params()` to the inner layered chart **before** faceting — Altair/Vega-Lite automatically hoists this to a single top-level param that drives every panel |
| Tooltip showing date + value | `mark_rule` layer filtered by the hover selection carries `Tooltip("date:T")` and `Tooltip("value:Q")` |
| Self-contained standalone HTML | `chart.save("chart.html", embed_options={"renderer": "svg"})` — all 180 data rows are inlined as a named dataset; no external data URL is referenced |

### Spec anatomy (verified by introspection)
- **`columns: 2`** → 2×2 grid of panels
- **`resolve.scale: {y: "independent", color: "shared"}`** → each panel auto-scales its own y-axis; all panels share one color scheme and one legend
- **`params`** at the top level → single `hover` selection drives all four panels simultaneously
- **`datasets`** → 180 rows inlined; `data.name` references the inline dataset, so the file renders with no network access
