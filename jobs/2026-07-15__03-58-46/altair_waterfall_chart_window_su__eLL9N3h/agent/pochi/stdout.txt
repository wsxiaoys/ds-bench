import pandas as pd, altair as alt, json

df = pd.read_csv("data/cash_flow.csv")
df["order"] = range(len(df))

base = alt.Chart(df).transform_window(
    cumulative_sum="sum(amount)",
    sort=[alt.SortField("order")],
    frame=[None, 0],
).transform_calculate(
    bar_start=(
        "datum.label === 'End'   ? 0 "
        ": datum.label === 'Begin' ? 0 "
        ": datum.cumulative_sum - datum.amount"
    ),
    bar_end="datum.cumulative_sum",
    bar_type=(
        "datum.label === 'Begin' || datum.label === 'End' ? 'Total' "
        ": datum.amount > 0 ? 'Increase' "
        ": 'Decrease'"
    ),
    label_text=(
        "datum.label === 'End' "
        "  ? format(datum.cumulative_sum, ',.0f') "
        "  : (datum.amount >= 0 ? '+' : '') + format(datum.amount, ',.0f')"
    ),
)

x_enc = alt.X("label:N", sort=alt.EncodingSortField(field="order", order="ascending"))
color_scale = alt.Scale(domain=["Increase","Decrease","Total"], range=["#3CA76E","#E05C5C","#5B8FD4"])
color_enc  = alt.Color("bar_type:N", scale=color_scale)

bars = base.mark_bar().encode(
    x=x_enc,
    y=alt.Y("bar_start:Q"),
    y2=alt.Y2("bar_end:Q"),
    color=color_enc,
)
text_labels = base.mark_text(baseline="bottom", dy=-4).encode(
    x=x_enc,
    y=alt.Y("bar_end:Q"),
    text=alt.Text("label_text:N"),
    color=alt.value("#333333"),
)

chart = alt.layer(bars, text_labels).properties(width=600, height=380)
spec = json.loads(chart.to_json())

print("Layer count:", len(spec.get("layer", [])))

### How it works

**Data loading**
```python
df = pd.read_csv("data/cash_flow.csv")
df["order"] = range(len(df))   # stable integer key to lock in CSV row order
```

**Window transform** — running cumulative sum
```python
.transform_window(
    cumulative_sum="sum(amount)",
    sort=[alt.SortField("order")],
    frame=[None, 0],             # sum from first row up to and including current
)
```

**Calculate transforms** — four derived fields

| field | expression |
|-------|-----------|
| `bar_start` | `0` for Begin/End, otherwise `cumulative_sum − amount` |
| `bar_end` | `cumulative_sum` (works for End too because its `amount` is 0) |
| `bar_type` | `"Total"` / `"Increase"` / `"Decrease"` for color encoding |
| `label_text` | `+1,200` style delta, or grand total for the End bar |

**Expected bar geometry** (verified by hand):

| Step | Delta | Running total | Bar span |
|------|------:|-------------:|---------|
| Begin | +4,000 | 4,000 | 0 → 4,000 |
| Product A | +1,200 | 5,200 | 4,000 → 5,200 |
| Product B | −800 | 4,400 | 5,200 → 4,400 |
| Services | +1,500 | 5,900 | 4,400 → 5,900 |
| Refunds | −600 | 5,300 | 5,900 → 5,300 |
| Tax | −900 | 4,400 | 5,300 → 4,400 |
| End | 0 | 4,400 | 0 → 4,400 |

**Layered chart**
- **Bar layer**: `y = bar_start`, `y2 = bar_end`, color driven by `bar_type` (green = increase, red = decrease, blue = total). Includes step/delta/running-total tooltips.
- **Text layer**: signed delta labels anchored just above each bar.

**Self-contained export**
```python
chart.save("waterfall.html", inline=True)
```
`inline=True` uses `vl-convert-python` to embed the Vega, Vega-Lite, and Vega-Embed JS bundles directly into the HTML, so no network connection is needed at render time.
