## Changes

### `server/routers/posts.ts`
Added a `list` procedure with zod input validation:
- `limit`: number between 1 and 50
- `cursor`: optional number (defaults to 0)
- Slices the `mockPosts` array from `cursor` to `cursor + limit`
- Returns `{ items, nextCursor }` where `nextCursor` is `cursor + limit` if more posts remain, otherwise `null`

```ts
list: publicProcedure
  .input(
    z.object({
      limit: z.number().min(1).max(50),
      cursor: z.number().optional(),
    })
  )
  .query(({ input }) => {
    const { limit, cursor = 0 } = input;
    const items = mockPosts.slice(cursor, cursor + limit);
    const nextCursor =
      cursor + limit < mockPosts.length ? cursor + limit : null;
    return { items, nextCursor };
  }),
```

### `app/components/PostList.tsx`
Uses `trpc.posts.list.useSuspenseInfiniteQuery` with `getNextPageParam` to extract `nextCursor` from the last page, flattens `pages` into a single list, and renders post titles in a `<ul>`. The `Load More` button calls `fetchNextPage()` and is disabled when `!hasNextPage || isFetchingNextPage`.

```tsx
const [{ pages }, { fetchNextPage, hasNextPage, isFetchingNextPage }] =
  trpc.posts.list.useSuspenseInfiniteQuery(
    { limit: 5 },
    { getNextPageParam: (lastPage) => lastPage.nextCursor }
  );

const posts = pages.flatMap((page) => page.items);
```
