## Changes Made

The `initTRPC.create()` call now includes the custom `errorFormatter`:

```typescript
export const t = initTRPC.create({
  errorFormatter({ shape, error }) {
    return {
      ...shape,
      data: {
        ...shape.data,
        zodError:
          error.code === 'BAD_REQUEST' && error.cause instanceof ZodError
            ? error.cause.flatten()
            : null,
      },
    };
  },
});
```

## How It Works

- When a `BAD_REQUEST` error occurs and its `cause` is a `ZodError` instance (e.g., when the `title` field is shorter than 5 characters), the `zodError` property is set to the flattened Zod error (`error.cause.flatten()`), which produces a `{ formErrors, fieldErrors }` shape.
- For all other errors, `zodError` is set to `null`.
- The original `shape` and `shape.data` are spread first, then `zodError` is appended to the `data` object — so the rest of the error shape is preserved.
