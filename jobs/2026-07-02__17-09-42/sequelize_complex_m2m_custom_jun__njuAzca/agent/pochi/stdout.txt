In this task, you will implement a Many-to-Many relationship with a custom junction table using Sequelize and SQLite in the project directory `/home/user/sequelize-m2m`. ## Requirements - Set up a Node.js project with Sequelize and SQLite. - Create three models: `User` (with `username`), `Project` (with `name`), and `UserProject` (with `role`). - Establish a Many-to-Many association between `User` and `Project` using `UserProject` as the junction model (`through` table). - Implement a CLI script `cli.js` with two commands: - `add <username> <project_name> <role>`: Creates the user (if not exists), the project (if not exists), and associates them with the given role. ## Key Implementation Details

**`db.js`** — Initializes Sequelize with the SQLite dialect, storing data in `./database.sqlite`.

**Models** — Each model uses `sequelize.define()` with a single attribute as specified: `username` on User, `name` on Project, and `role` on UserProject.

**`models/index.js`** — Establishes the bidirectional `belongsToMany` association using `UserProject` as the `through` table:
```js
User.belongsToMany(Project, { through: UserProject, foreignKey: 'UserId', otherKey: 'ProjectId' });
Project.belongsToMany(User, { through: UserProject, foreignKey: 'ProjectId', otherKey: 'UserId' });
```

**`cli.js`** — Two commands parsed from `process.argv`:
- `add <username> <project_name> <role>` — Uses `findOrCreate` for both User and Project, then `UserProject.upsert()` to associate them with the role. Prints the exact confirmation format.
- `list <username>` — Fetches the user with `include: { model: Project, through: { attributes: ['role'] } }` to get the junction attributes, then maps each project to `{ name, role }` and outputs JSON.

The script calls `sequelize.sync()` before any query and `sequelize.close()` in the finally block to release resources.

- Users with no projects and non-existent users return `[]`
