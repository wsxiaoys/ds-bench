## Pipeline structure

1. **Static enrichment data** – `products.json` is loaded into the `PRODUCTS` module-level dict at import time.

2. **Input** – `FileSource("transactions.jsonl")` streams the JSONL file line-by-line; `flat_map_batch` decodes each line into a dict.

3. **Enrichment & filtering** – `filter_map("enrich", …, _enrich)` joins each transaction with its product metadata (computing `revenue = price × quantity` and a minute-aligned `window_start`). It returns `None` for unknown product IDs, dropping those transactions silently.

4. **Keying** – `key_on("by_category", …)` keys by the product `category`, so each category gets its own windowed aggregation.

5. **Event-time clock** – `EventClock(ts_getter=lambda x: x["event_time"], wait_for_system_duration=timedelta(seconds=10))`. Timestamps are parsed via `datetime.fromisoformat` after replacing the trailing `Z` with `+00:00`, producing timezone-aware UTC datetimes.

6. **1-minute tumbling window aligned to the start of the hour** – `TumblingWindower(length=timedelta(minutes=1), align_to=datetime(1970, 1, 1, 0, 0, 0, tzinfo=timezone.utc))`. Aligning to epoch gives windows that start exactly on every minute boundary, so the first window in any hour begins at `:00`.

7. **Aggregation** – `fold_window` with `builder -> (seed_window, 0.0)`, a `folder` that adds each new revenue to the total (adopting the incoming event's `window_start` instead of the seed on the very first call), and a `merger` that combines two partial accumulators.

8. **Output** – `op.map` formats each `(category, (wid, (window_start, revenue)))` tuple into the required JSON string (with `window_start` rendered as an ISO-8601 `…Z` timestamp) and `op.output` writes the result to `StdOutSink`.
