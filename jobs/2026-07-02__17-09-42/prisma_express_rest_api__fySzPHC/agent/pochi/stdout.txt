- **`prisma/schema.prisma`** — Defines `User` (id, email @unique, name) and `Task` (id, title, description?, status @default("todo"), priority @default(0), userId FK, createdAt, updatedAt) with cascade delete, plus indexes on `userId` and `status` for fast filtering.

## Endpoints

| Method | Route | Description |
|---|---|---|
| `POST` | `/users` | Create user. Body: `{ email, name }`. Returns 201 / 400 / 409. |
| `POST` | `/tasks` | Create task. Body: `{ title, description?, userId, priority? }`. Returns 201 / 400 / 404. |
| `GET` | `/tasks` | List all tasks. Supports `?status=...` and `?userId=...` filters (combinable). |
| `GET` | `/tasks/:id` | Get single task with `user` included. Returns 404 if missing. |
| `PATCH` | `/tasks/:id` | Partial update of `title`, `description`, `status`, `priority`. |
| `DELETE` | `/tasks/:id` | Delete task, returns 204 (or 404). |

Plus: input validation, async error handling, JSON 404 handler, graceful shutdown on SIGINT/SIGTERM, and cascade delete verified.
