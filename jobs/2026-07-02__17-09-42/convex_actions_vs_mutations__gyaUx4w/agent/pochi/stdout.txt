Refactored the Convex code so the external-API side effect lives in an `action` and only the pure database write happens in a `mutation`, while keeping data isolated per run via a unique table name.

## Run-id → table name
- `/logs/artifacts/run-id` (trimmed): `zrpy82jd8t`
- All characters are alphanumeric, so the suffix is `zrpy82jd8t`.
- Table name: `tasks_zrpy82jd8t` (16 chars, well under the 64-char Convex limit).

## `convex/schema.ts`
```ts
import { defineSchema, defineTable } from "convex/server";
import { v } from "convex/values";

export default defineSchema({
  tasks_zrpy82jd8t: defineTable({
    title: v.string(),
    isCompleted: v.boolean(),
  }),
});
```

## `convex/tasks.ts`
```ts
import { action, mutation } from "./_generated/server";
import { v } from "convex/values";

export const saveTask = mutation({
  args: { title: v.string() },
  handler: async (ctx, args) => {
    const taskId = await ctx.db.insert("tasks_zrpy82jd8t", {
      title: args.title,
      isCompleted: false,
    });
    return taskId;
  },
});

export const fetchAndSave = action({
  args: {},
  handler: async (ctx) => {
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/todos/1",
    );
    const data = await response.json();

    const taskId = await ctx.runMutation(saveTask, { title: data.title });
    return taskId;
  },
});
```

## Why this fixes the bug
- Convex mutations must be deterministic, so `fetch` inside `addTaskWithApi` was illegal. Moving the side-effectful HTTP call into `fetchAndSave` (an `action`) makes it valid.
- The mutation `saveTask` only does the pure insert; the action invokes it via `ctx.runMutation(saveTask, ...)` and returns the new task ID.
- The table name is derived from `/logs/artifacts/run-id` once and reused identically in both `convex/schema.ts` (where the table is declared) and `convex/tasks.ts` (where rows are inserted), so schema and writes stay in sync and stay isolated from other runs.

- ✅ `convex/schema.ts` defines `tasks_zrpy82jd8t` with `title: v.string()` and `isCompleted: v.boolean()`.
- ✅ Table name starts with a letter, contains only letters/digits/underscores, and is 16 characters (≤ 64).
