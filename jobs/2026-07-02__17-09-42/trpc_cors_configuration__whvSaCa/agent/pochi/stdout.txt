### 🔑 Key implementation details in `index.ts`

1. **tRPC v11 initialization** — uses `initTRPC.create()` to obtain the root tRPC object, then `t.router` and `t.procedure` to build the API.
2. **`hello` query** — accepts an optional `{ text: string }` input validated by `zod`, returns `{ greeting: 'hello <text>' }` (defaults to `"world"` when no input is provided).
3. **CORS via the built-in `middleware` option** — `createHTTPServer` in v11 accepts a `middleware` field for any Connect-style middleware. We wire up the `cors` package and lock it down to `origin: 'http://localhost:3000'`.
4. **Port 4000** — `server.listen(4000)` matches the requirement.
5. **Run script** — `npm run start` (which invokes `npx tsx index.ts`) per the spec, with an additional `npm run dev` for hot-reload.
