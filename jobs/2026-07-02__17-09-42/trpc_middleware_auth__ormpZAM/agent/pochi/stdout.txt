## Implementation Summary

**`createContext`** — reads the `authorization` header from `req.headers` and sets the user:
```ts
export function createContext({ req, res }: any) {
  const authHeader = req.headers.authorization;
  if (authHeader === 'Bearer mysecrettoken') {
    return { user: { id: 1, name: 'Admin' } };
  }
  return { user: null };
}
```

**`isAuthed` middleware** — throws `TRPCError` with code `UNAUTHORIZED` when `ctx.user` is missing, and narrows the context for downstream procedures by passing only the non-null `user` forward:
```ts
const isAuthed = t.middleware(({ next, ctx }) => {
  if (!ctx.user) {
    throw new TRPCError({ code: 'UNAUTHORIZED' });
  }
  return next({
    ctx: {
      user: ctx.user,
    },
  });
});
```

**`protectedProcedure`** — chains the middleware:
```ts
const protectedProcedure = t.procedure.use(isAuthed);
```

**`appRouter`** — defines the `secretData` query:
```ts
export const appRouter = t.router({
  secretData: protectedProcedure.query(() => {
    return { secret: 'super secret' };
  }),
});
```

The server starts on port 3000 via `createHTTPServer({ router: appRouter, createContext }).listen(3000)`.
