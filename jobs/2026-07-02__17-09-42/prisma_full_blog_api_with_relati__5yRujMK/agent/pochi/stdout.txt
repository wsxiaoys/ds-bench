## Project structure

## Endpoints (all verified working)
- `POST /users` — Create user (`{ email, name }`)
- `GET /users/:id/posts` — Returns **only published** posts by the user, each with `_count.comments`
- `POST /posts` — Create post (`{ title, content?, authorId }`); `content` optional, defaults to `null`
- `PATCH /posts/:id/publish` — Sets `published: true` (returns 404 via Prisma `P2025` if post missing)
- `POST /posts/:id/comments` — Add a comment (`{ body, authorId }`)
- `GET /posts/:id` — Returns the post with `author` and nested `comments[].author`
