## Project Structure

- `src/App.tsx` — Main app using `useReactTable` + `getCoreRowModel` from `@tanstack/react-table`; tracks the `editingId` in component state to toggle each row between display and edit modes
- `src/EditableRow.tsx` — Editable row powered by `useForm` from `@tanstack/react-form` with field-level validators and per-field error rendering
- `src/App.css` + `src/index.css` — Clean, responsive styling with light/dark mode support

## Key Implementation Details

**TanStack Table (`App.tsx`)**
- Columns defined via `ColumnDef<User>` with `id`, `name`, `email`, `role`, and `actions`
- Rows come from `table.getRowModel().rows` and are rendered with `flexRender`
- When `editingId === user.id`, the normal row is replaced with `<EditableRow />`; all other Edit buttons are disabled so only one row can be edited at a time

**TanStack Form (`EditableRow.tsx`)**
- `useForm` initialised with `defaultValues` from the current row data and an `onSubmit` that calls `onSave` to commit changes back into table state
- `name` field: `onChange` + `onBlur` validators require a non-empty string ("Name is required")
- `email` field: `onChange` + `onBlur` validators check non-empty + a regex matching `^[^\s@]+@[^\s@]+\.[^\s@]+$` ("Email is required" / "Email must be a valid format")
- Inputs render error messages beneath them and add an `.input-error` class for visual feedback
- Save button is disabled when `state.canSubmit` is false and shows "Saving…" during submission; invalid data prevents saving entirely
- Cancel simply calls `onCancel` which clears `editingId` — TanStack Form unmounts with the row, reverting any state
