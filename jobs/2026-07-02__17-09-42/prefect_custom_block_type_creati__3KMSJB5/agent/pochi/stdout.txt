## Files

**`/home/user/myproject/custom_block.py`** — Defines the custom block type.

```python
from pydantic import SecretStr
from prefect.blocks.core import Block


class DatabaseConfig(Block):
    """A Prefect Block that stores database connection configuration."""

    host: str
    port: int = 5432
    password: SecretStr

    _block_type_name = "Database Config"
    _logo_url = "https://images.ctfassets.net/gm98wzqotmnx/2IfwofbalDYIykVcWNg6Vi/ae1d8aaece81aa6f4d8b4a4ad77b8d0c/image.png?w=64&h=64"
    _documentation_url = "https://prefect.io/docs"
```

- Subclasses `prefect.blocks.core.Block`.
- `host: str` (required).
- `port: int` with default `5432`.
- `password: SecretStr` (Pydantic secret string, so the value is obfuscated in repr and registered as a secret field by Prefect).
- Importing this module registers the block type with the Prefect API under the slug `database-config`.

**`/home/user/myproject/setup_block.py`** — Imports the block (registering it) and persists an instance named `my-db-config`.

```python
config = DatabaseConfig(
    host="localhost",
    port=5432,
    password=SecretStr("supersecret"),
)
config.save(name="my-db-config", overwrite=True)
```

It also sets `PREFECT_TELEMETRY_ENABLED=false` before importing Prefect to avoid SQLite `database is locked` errors from the telemetry heartbeat service racing the save on a local DB.

**`/home/user/myproject/load_block.py`** — Loads the saved block and prints its host.

```python
config = DatabaseConfig.load("my-db-config")
print(config.host)
```
