```python
class State(rx.State):
    show_panel: bool = False

    @rx.var(cache=True)
    def visibility_label(self) -> str:
        return f"Visibility: {'shown' if self.show_panel else 'hidden'}"

    def set_show_panel(self, value: bool) -> None:
        self.show_panel = value
```
- `show_panel: bool = False` has the explicit type annotation and default.
- `visibility_label` is marked `@rx.var(cache=True)` and returns a `str`.

**Index page** wires:
- `rx.switch(checked=State.show_panel, on_change=State.set_show_panel)` — the boolean emitted by the switch updates `show_panel`.
- `rx.cond(State.show_panel, rx.box(rx.text("Secret Panel Content"), ...), rx.fragment())` — shows the panel only when toggled on.
- `rx.text(State.visibility_label)` — renders the cached status label "Visibility: shown" / "Visibility: hidden".
