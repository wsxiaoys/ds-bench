## Implementation highlights (`SimMain.java`)

- `main(String[] args)` validates the two positional args, builds a `HeadlessApplicationConfiguration` with `updatesPerSecond = 0` (so the loop runs as fast as possible), constructs a `HeadlessApplication` and joins on its main loop thread.
- A tiny `SimApplication` subclass of `HeadlessApplication` exposes the protected `mainLoopThread` field — libGDX doesn't provide a public accessor for it, so a subclass is the cleanest way to obtain the thread for `join()`.
- The `SimListener` `ApplicationListener`:
  - **`create()`** reads the config via `Gdx.files.absolute(configPath).read()` into a `Properties` object.
  - **`render()`** performs exactly one Symplectic Euler step per call (`vx += 0*dt; vy += gravityY*dt; x += vx*dt; y += vy*dt`), increments `ticksExecuted`, and calls `Gdx.app.exit()` once the requested tick count is reached. For `ticks=0` it calls `exit()` on the very first frame, so the output reflects the initial state unchanged.
  - **`dispose()`** writes the final state using `BufferedWriter` + `OutputStreamWriter(StandardCharsets.UTF_8)`, joined with `'\n'` separators. Numbers are formatted with `String.format(Locale.ROOT, "%.6f", value)`.
- No calls to `Gdx.gl*` are made — the listener is pure simulation logic.
