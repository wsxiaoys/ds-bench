1. **Creates a new E2B sandbox** with a 600-second timeout via `Sandbox.create(timeout=SANDBOX_TIMEOUT_SECONDS)`.
2. **Installs `uv`** inside the sandbox by running the official installer and exports `$HOME/.local/bin` on `PATH`.
3. **Creates a virtual environment** at `/home/user/venv` using `uv venv /home/user/venv`.
4. **Installs `pandas` and `numpy`** into that venv with `uv pip install --python /home/user/venv/bin/python pandas numpy`.

6. **Writes the sandbox ID to `/home/user/e2b_task_info.json`** locally in `{"sandbox_id": "<id>"}` format.
7. **Leaves the sandbox running** (no `with` block / no `sandbox.kill()`), so the REDACTEDmated tests can connect and verify it before the timeout expires.

### Key design choices
- `Sandbox.__exit__` calls `kill()`, so the sandbox is created directly (not as a context manager). It is only killed in an `except` branch if setup fails.
- The script pre-exports `PATH="$HOME/.local/bin:$PATH"` for every `uv` invocation to be safe across shells.
- The pandas version is captured by redirecting `sys.stdout.write(pd.__version__)` to `/home/user/pandas_version.txt`.
