**`index.js` highlights**
- `initTRPC.create()` to bootstrap tRPC v11.
- A single public procedure `greeting` that takes `z.object({ name: z.string() })` and returns `Hello, ${name}!`.
- A `makePanelCompatibleRouter` shim that recursively walks the v11 router and sets `_def.query = true` / `_def.mutation = true` / `_def.subscription = true` on each procedure based on its v11 `_def.type`. This is required because `trpc-panel` was written for tRPC v10 (which had `query: true` literals on `_def`) and v11 replaced those with a single `type: "query" | "mutation" | "subscription"` field.
- `app.use('/trpc', createExpressMiddleware({ router: appRouter }))` from `@trpc/server/adapters/express` mounts the API.
- `app.use('/panel', …)` serves the HTML returned by `renderTrpcPanel(panelCompatibleRouter, { url: 'http://localhost:3000/trpc' })`.
