2. **Migration** — ran `prisma migrate dev --name init`, which created `prisma/migrations/.../migration.sql` and the SQLite DB.
3. **Prisma client** — generated via `prisma generate`. Prisma 7 requires a driver adapter for SQLite, so `@prisma/adapter-better-sqlite3` and `better-sqlite3` were installed and wired into `new PrismaClient({ adapter })`.
4. **Server** (`server.js`) — Express on port 3000.

## How RLS is enforced

A single base `prisma` client is created. Inside `getTenantClient(tenantId)`, `prisma.$extends({ query: { item: { … } } })` is used to wrap every `item.*` operation:

- **Reads** (`findMany`, `findFirst`, `findFirstOrThrow`, `findUnique`, `findUniqueOrThrow`, `count`, `aggregate`, `groupBy`): `args.where = { ...args.where, tenantId }` is merged in.
- **Writes**:
  - `create` / `createMany` inject `tenantId` into `data`.
  - `update` / `updateMany` / `delete` / `deleteMany` merge `tenantId` into `where`.
  - `upsert` injects `tenantId` into both `where` and `create`.

Because the extension overrides any caller-supplied value, a request can never read or write another tenant's rows, even if the body contains a different `tenantId`.

Each request handler calls `getTenantClient(req.header('x-tenant-id'))` and uses the returned scoped client. Missing/invalid header → `400`.

## Endpoints

| Method | Path | Behavior |
| --- | --- | --- |
| GET | `/items` | Returns items whose `tenantId` matches the `x-tenant-id` header |
| POST | `/items` | Body `{ name }`, creates item with `tenantId` set from the header |

## Verified behaviors

```
POST /items (no header)           → 400 Missing x-tenant-id header
POST /items  x-tenant-id: acme    → 201 {id, name, tenantId:"acme"}
POST /items  body.tenantId=globex → 201 {…, tenantId:"acme"}   ← extension overrides
POST /items  body={}              → 400 Body must include { name: string }
GET  /items  x-tenant-id: acme    → [A1, A2]                   ← only acme's rows
GET  /items  x-tenant-id: globex  → [B1]                       ← only globex's rows
GET  /items  x-tenant-id: initech → []                         ← isolated empty
GET  /items  (no header)          → 400
```
