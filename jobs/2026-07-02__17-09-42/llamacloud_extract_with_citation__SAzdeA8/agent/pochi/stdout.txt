## What the script does

1. **Reads the run-id** from `/logs/artifacts/run-id` and computes `external_file_id="invoice-${run-id}.txt"` so concurrent runs don't collide in the dashboard.
2. **Uploads the file** via `client.files.create(..., purpose="extract", external_file_id=...)`. It gracefully falls back to reusing the existing file id if a previous run with the same run-id already uploaded it.
3. **Creates the extract job** with a JSON Schema covering the three required leaf fields (`company_name`, `invoice_number`, `total_amount`) and the configuration `{"extraction_target": "per_doc", "tier": "agentic", "cite_sources": True}`.
4. **Polls** the job with `client.extract.get(job_id, expand=["extract_metadata"])` (the `expand` is what makes the per-field citation tree come back; without it `extract_metadata` is `None`). Raises loudly on `FAILED`/`CANCELLED`.
5. **Writes `output.log`** with the exact lines:
   - `Extract job: ext-…`
   - `Status: COMPLETED`
6. **Writes `result.json`** containing `data` (the three leaf values) and `extract_metadata.field_metadata` (each leaf's `citation` array with `page` and `matching_text`).
