## What it does
1. Reads the `E2B_API_KEY` environment variable and writes it to `/home/user/e2b_api_key.txt`.
2. Spawns a new sandbox via `Sandbox.create(timeout=600)`. Passing no `template` argument uses E2B's default template (`base`), and `timeout=600` keeps the sandbox alive for 10 minutes.
3. Persists the spawned sandbox's ID to `/home/user/sandbox_id.txt` immediately after creation.
4. Runs `echo 'Hello E2B' > /home/user/hello.txt` inside the sandbox (the command succeeded with exit code 0).
