**Project layout** (`/home/user/project`):

- **`server.ts`** — tRPC server on port `3000` built with `@trpc/server`'s standalone adapter. The `countdown` procedure is declared as `publicProcedure.input(z.number()).subscription(async function* (opts) { ... })`, an async generator that yields numbers from the input down to `0` with a `100 ms` delay between each yield. SSE is enabled via `initTRPC.create({ sse: { client: { reconnectAfterInactivityMs: 3_000 }, ping: { enabled: true, intervalMs: 2_000 } } })`.

- **`client.ts`** — tRPC client using `httpSubscriptionLink` (paired with `httpBatchLink` via `splitLink` for non-subscription ops). Node.js has no built-in `EventSource`, so the `eventsource` package is injected through the `EventSource` option. The client calls `trpc.countdown.subscribe(3, { onData, onError, onComplete })`, printing each emitted number to stdout, and exits when the subscription completes.
