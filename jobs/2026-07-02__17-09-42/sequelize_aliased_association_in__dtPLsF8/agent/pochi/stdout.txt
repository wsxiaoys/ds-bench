## Summary of Implementation

**1. Sequelize Initialization** — Connected to `./database.sqlite` with logging disabled to keep stdout clean.

**2. Model Definitions**
- `Person` with a `name: STRING` field
- `Mail` with a `content: STRING` field

**3. Aliased Associations** — The critical part for avoiding the "Include unexpected" error:
```javascript
Mail.belongsTo(Person, { as: 'sender',   foreignKey: 'senderId'   });
Mail.belongsTo(Person, { as: 'receiver', foreignKey: 'receiverId' });
```
Explicit `foreignKey` values for each alias ensure Sequelize generates two distinct foreign key columns (`senderId` and `receiverId`) on the `Mails` table. This is the key to correctly defining multiple associations between the same two models.

**4. Eager Loading** — The query uses the exact same alias names in the `include` array:
```javascript
const mail = await Mail.findOne({
  include: [
    { model: Person, as: 'sender' },
    { model: Person, as: 'receiver' },
  ],
});
```
Because the aliases on the `belongsTo` definitions match the aliases on the `include`, Sequelize resolves them without throwing the "Include unexpected" error.

**5. Output** — After syncing with `force: true`, creating Alice and Bob, and creating a mail from Alice → Bob with content `"Hello"`, the script prints exactly:

