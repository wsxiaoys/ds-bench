## Implementation Details (`convex/accounts.ts`)

**`createAccount`** — Inserts an account with the given `name` and `initialBalance`.

**`getBalance`** — Uses the `by_name` index to look up the account and returns `balance` as a number. Throws if not found.

**`transfer`** — Atomically transfers `amount` from `fromName` to `toName`:
1. Throws `"Transfer amount must be greater than zero"` if `amount <= 0`.
2. Looks up both accounts via the `by_name` index.
3. Throws `"Insufficient balance"` if `fromAccount.balance < amount`.
4. `ctx.db.patch`es both accounts (decrement source, increment destination).

Because Convex mutations are REDACTEDmatically transactional, throwing an error rolls back any partial updates — so the source account can never be debited without the destination being credited.
