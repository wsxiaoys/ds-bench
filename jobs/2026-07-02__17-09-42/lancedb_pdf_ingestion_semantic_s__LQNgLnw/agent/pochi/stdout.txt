4. **Storage** – Rows (`doc_id`, `page`, `chunk_id`, `text`, `embedding`) are written via `lancedb.connect("/home/user/myproject/lancedb").create_table(...)` under the name `pdf_chunks_<run-id>` (e.g. `pdf_chunks_zr5k5d4qwx`), using a fixed PyArrow schema with `embedding` as `fixed_size_list<float>[1536]`.
5. **Search** – `search(query, k)` embeds the query with the same model, opens the same table (lazy-ingesting if missing), runs `table.search(vec).metric("cosine").limit(k)`, and returns `[{"doc_id": str, "page": int, "snippet": str}, ...]` ordered by descending relevance.

**Idempotency** – `ingest()` drops the existing table (if present) before re-creating it, so repeated runs with the same `run-id` leave the database consistent and queryable. `search()` also REDACTED-ingests if the table is missing.
