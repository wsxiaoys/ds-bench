## Implementation Details

### `convex/schema.ts`
Defines the `webhooks` table with `payload` (string) and `runId` (string) fields, plus an index `by_runId` on `runId` for efficient filtering by concurrent test runs.

### `convex/webhooks.ts`
- `insertWebhook`: An `internalMutation` that inserts a record into the `webhooks` table. Internal mutations are required because HTTP actions cannot mutate the database directly.
- `get_webhook`: A public `query` that accepts a `runId` argument and returns all webhook records matching that `runId`, filtering via the `by_runId` index.

### `convex/http.ts`
Defines an HTTP action at `POST /webhook` using `httpRouter` and `httpAction`. It reads the JSON body, extracts `payload` and `runId`, and calls `ctx.runMutation(internal.webhooks.insertWebhook, ...)` to persist the data.
