### What the script does

1. **Auth** — Instantiates `LlamaCloud()`, which picks up `LLAMA_CLOUD_API_KEY` from the environment REDACTEDmatically.
2. **Upload** — Calls `client.files.create(file=..., purpose="parse")` on `data/sales.xlsx`, returning a `file_id`.
3. **Sheets parse** — Calls `client.beta.sheets.parse(file_id=..., config={"generate_additional_metadata": True})`. This one-shot helper creates the job, polls to completion, and returns the final `SheetsJob` with `regions`, `worksheet_metadata`, etc.
4. **Per-region download** — For every detected region it calls `client.beta.sheets.get_result_table(region_type=region.region_type, spreadsheet_job_id=job.id, region_id=region.region_id)` to fetch a presigned URL, then streams the bytes via `httpx` to `/home/user/project/output/region_<region_id>.parquet`.
5. **Structured log** — Appends the required lines to `/home/user/project/output/sheets.log`.
