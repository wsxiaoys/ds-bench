## How the auth flow works

- **Auth state (`src/auth.tsx`)**: A React Context holds `isAuthenticated: boolean` (default `false`) with `login()` and `logout()` updaters, exposed via the `useAuth()` hook. The `AuthRouterContext` type is exported so the router can be typed against it.

- **Router wiring (`src/main.tsx`)**: `App` calls `useAuth()` and passes the result into `<RouterProvider context={{ auth }} />`, which is what makes `auth` reachable inside route-level `beforeLoad` hooks.

- **Route protection (`src/routes/dashboard.tsx`)**:
  ```ts
  beforeLoad: ({ context }) => {
    if (!context.auth?.isAuthenticated) {
      throw redirect({ to: '/login' });
    }
  }
  ```
  Any unauthenticated navigation to `/dashboard` is intercepted before the component renders and thrown to `/login`.

- **Login page**: The "Login" button calls `auth.login()` and then `navigate({ to: '/dashboard' })`.

- **Dashboard page**: Renders "Welcome to Dashboard" and a "Logout" button that calls `auth.logout()` and navigates to `/login`.
