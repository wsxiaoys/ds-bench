**The script content:**
```python
from prefect import task, flow


def cache_key_for_fetch(context, parameters):
    return "fetch-" + parameters["url"]


@task(cache_key_fn=cache_key_for_fetch)
def fetch_data(url: str) -> str:
    return "Data from " + url


@flow
def process_data():
    result_1 = fetch_data("http://example.com")
    result_2 = fetch_data("http://example.com")
    print(result_1)
    print(result_2)


if __name__ == "__main__":
    process_data()
```

**Key implementation details:**
- Uses Prefect 3.0 syntax (`@task`, `@flow`)
- `cache_key_fn` is set to `cache_key_for_fetch`, which accepts `context` and `parameters` and returns `"fetch-" + parameters["url"]`
- The `process_data()` flow calls `fetch_data("http://example.com")` twice and prints both results
- The `if __name__ == "__main__"` guard ensures the flow runs when the script is executed directly
