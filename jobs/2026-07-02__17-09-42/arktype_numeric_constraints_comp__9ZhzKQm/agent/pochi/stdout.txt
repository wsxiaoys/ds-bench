### `src/validator.ts`
Exports the `Discount` schema and `validateDiscount(input: unknown)` function. The schema combines all four constraints:

- **`percent`** — `"1 <= number.integer <= 99 & (number % 5)"`: combines integer constraint, inclusive numeric range, and `% 5` divisibility via ArkType's string-embedded intersection syntax.
- **`amount`** — `"0 < number < 10000"` with `.narrow((n, ctx) => …)` enforcing "at most 2 decimal places" using ArkType's narrow predicate API (no separate regex pre-check).
- **`validityDays`** — `"1 <= number <= 365"` inclusive integer range.
- **`appliesTo`** — `type.enumerated("cart", "shipping", "item")` literal union.

`validateDiscount` returns a discriminated union:
- `{ valid: true, data: Discount }` on success
- `{ valid: false, error: string }` on failure (error comes from `result.summary`)

### `cli.ts`
Reads a single JSON payload from stdin, validates it via `validateDiscount`, and writes either:
- `VALID\n<json>\n` for successful validation, or
- `INVALID: <error description>\n` for any failure (including malformed JSON)

The CLI always exits with code 0, as required.
