Built a Laplacian structural music segmentation pipeline using librosa 0.11.0. The script is at `/home/user/segment.py` and writes `/home/user/segments.json`.

**Pipeline steps implemented:**

1. **Load**: `librosa.load('/home/user/input.wav', sr=22050, mono=True)` → 33.0 s mono audio.
2. **Beat tracking**: Compute `onset_envelope` explicitly and call `librosa.beat.beat_track` (50 beats at ~89.1 BPM). The explicit-envelope path is needed because the default `y`-based path returned 0 beats in this librosa build.
3. **Beat-synchronous tonal feature**: `librosa.feature.chroma_cqt` → `librosa.util.sync(..., aggregate=np.median)` → beat-synchronous chroma of shape `(12, 51)`, L2-normalized for cosine-style similarity.
4. **Recurrence + path enhancement**: `librosa.segment.recurrence_matrix(mode='affinity', metric='cosine', sym=True, bandwidth=3)` followed by `librosa.segment.path_enhance` over `n_beats` diagonal paths, symmetrized and clipped to `[0,1]`.
5. **Sequential affinity**: Gaussian local affinity over a 3-beat neighborhood (`sigma=1.0`).
6. **Combined weighted adjacency**: `W = 0.7 * R_path + 0.3 * seq`, symmetrized.
7. **Symmetric normalized Laplacian**: `L_sym = I - D^{-1/2} W D^{-1/2}`, eigendecomposed with `np.linalg.eigh`; the K=5 smallest non-trivial eigenvectors form the embedding, which is then row-normalized.
8. **Clustering**: `sklearn.cluster.AgglomerativeClustering(n_clusters=3, linkage='ward')` on the embedding.
9. **Time mapping**: `librosa.util.fix_frames` builds a beat-boundary frame list (with a trailing frame appended so the last beat has an end), `librosa.frames_to_time` produces absolute times, then contiguous runs of labels become `(start, end)` intervals. Letters `A/B/C…` are assigned by first-appearance order; the first run is forced to `start=0.0` and the last to `end=duration`.
