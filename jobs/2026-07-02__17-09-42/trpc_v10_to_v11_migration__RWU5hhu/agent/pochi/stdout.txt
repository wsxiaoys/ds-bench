### 1. `package.json` — Upgraded dependencies

- `@tanstack/react-query`: `^4.36.1` → `latest` (resolved to **v5.101.2**)

### 2. `src/utils/trpc.ts` — Migrated transformer config
In tRPC v11, the `transformer` option was removed from the root client config and is now configured per-link. The change moves `transformer: superjson` from the root of the `config()` return into `httpBatchLink`:

```ts
export const trpc = createTRPCNext<AppRouter>({
  config() {
    return {
      links: [
        httpBatchLink({
          url: `${getBaseUrl()}/api/trpc`,
          transformer: superjson, // moved here from root
        }),
      ],
    };
  },
  ssr: false,
});
```
