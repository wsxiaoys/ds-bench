# libGDX Headless: 2D Shape Overlap Collision Report ## Background libGDX ships a non-rendering backend (`com.badlogicgames.gdx:gdx-backend-headless`) that swaps the live `Graphics`/`Input`/`Audio` implementations for mocks so a libGDX `ApplicationListener` can be driven from a server, CI runner, or test harness. The framework's math package (`com.badlogic.gdx.math`) is fully usable from this backend and ships ready-made 2D collision primitives: `Rectangle.overlaps(Rectangle)`, `Circle.overlaps(Circle)`, and `Intersector.overlaps(Circle, Rectangle)`. Servers and offline batch jobs frequently lean on these primitives to detect collisions, validate level layouts, or pre-compute spatial indices without ever opening a window. In this task you will build a small libGDX 1.14.2 project around the **headless** backend that consumes a 2D shape description file, computes every overlapping pair using libGDX's own geometry classes, and writes a sorted collision report to disk. ## Requirements * Create a Gradle (Java 17) project at `/home/user/gdx-game` that depends on libGDX `1.14.2` (`gdx`, `gdx-backend-headless`, `gdx-platform:natives-desktop`). * Implement a libGDX `ApplicationListener` (or `ApplicationAdapter`) that runs under `com.badlogic.gdx.backends.headless.HeadlessApplication`. * Inside the listener's `create()` callback (or driven from `render()` on the very first tick) load the shape definition file via `Gdx.files.absolute(<path>)`, parse it, compute every overlapping pair using libGDX's math primitives, write the report file, and call `Gdx.app.exit()` so the headless main loop terminates cleanly. * Pairwise overlap detection MUST use the libGDX classes `com.badlogic.gdx.math.Rectangle`, `com.badlogic.gdx.math.Circle`, and `com.badlogic.gdx.math.Intersector` (specifically `Rectangle.overlaps(Rectangle)`, `Circle.overlaps(Circle)`, and `Intersector.overlaps(Circle, Rectangle)`). Do **NOT** re-implement the geometry checks by hand. * Produce a runnable launcher (via the Gradle `application` plugin) at `/home/user/gdx-game/build/install/gdx-game/bin/gdx-game` that accepts two arguments using the exact equals form: `--shapes=<input_path>` and `--output=<output_path>`, both absolute paths. ### Input file format * UTF-8 text file. * Lines starting with `#` are comments and are skipped. * Blank/whitespace-only lines are skipped. * Each non-comment, non-blank line defines exactly one shape using whitespace as the delimiter: * Rectangle: `<id> rect <x> <y> <width> <height>` * Circle: `<id> circle <x> <y> <radius>` * `<id>` is a non-empty token consisting of letters, digits, underscores, or hyphens (no whitespace). IDs are case-sensitive and must be unique within a file; on a duplicate ID the program must print `Error: duplicate id <id>` to stderr and exit with a non-zero status code. * Numeric coordinates and dimensions are decimal floating-point numbers parseable by `Float.parseFloat`. `width`, `height`, and `radius` must be strictly positive. * Any malformed line (unknown shape keyword, wrong number of tokens, non-positive size, unparseable number) must cause the program to print `Error: invalid shape line: <line>` (substituting the offending raw line verbatim, without the trailing newline) to stderr and exit with a non-zero status code. ### Output file format * UTF-8 text file written to the path supplied via `--output=<path>`. If the file already exists it must be overwritten. * One overlapping pair per line, formatted exactly as `<id_a>\t<id_b>` (tab-separated). Within each pair the lexicographically smaller ID (using Java string `compareTo`) MUST appear first. * Lines MUST be sorted lexicographically: primary key is the first id (`id_a`), secondary key is the second id (`id_b`). * A final summary line `total_overlaps=<N>` MUST be appended after the pair listing, where `<N>` is the total number of distinct overlapping pairs. * If no shapes overlap, the file must contain a single line `total_overlaps=0`. * The file MUST end with a single trailing newline. ### Overlap semantics * Two rectangles overlap iff `Rectangle.overlaps(Rectangle)` returns `true` (strict, edge-touching does NOT count). * Two circles overlap iff `Circle.overlaps(Circle)` returns `true` (strict distance check, tangent circles do NOT count). * A circle and a rectangle overlap iff `Intersector.overlaps(Circle, Rectangle)` returns `true`. * Each unordered pair is reported at most once. ## Implementation Hints * Pin `gdxVersion=1.14.2`. The required Maven coordinates and the headless backend recipe are summarised in the libGDX docs (https://libgdx.com/wiki/articles/dependency-management-with-gradle, https://github.com/libgdx/libgdx/blob/master/backends/gdx-backend-headless/src/com/badlogic/gdx/backends/headless/HeadlessApplication.java). * The Gradle `application` plugin gives you a turnkey launcher: configure `mainClass` and run `./gradlew installDist` to produce `build/install/<projectName>/bin/<projectName>`. * `HeadlessApplication` boots its `ApplicationListener` on its own thread; the launcher's `main` thread should wait for the listener to call `Gdx.app.exit()` (e.g., by joining the headless main-loop thread) before exiting, otherwise the JVM may quit before the output file is flushed. * Use `HeadlessApplicationConfiguration.updatesPerSecond = 0` (or a small positive number) so the main loop does not busy-wait; `create()` runs on the very first tick. * The headless backend is sensitive to OpenGL calls — do **NOT** touch `Gdx.gl*` anywhere in your code. * Bootstrap the Gradle wrapper with `gradle wrapper --gradle-version 8.10 --distribution-type bin` so reproducible builds are possible from the project root. * libGDX's geometry classes live in `com.badlogic.gdx.math`. `Rectangle` is constructed as `new Rectangle(x, y, width, height)`, `Circle` as `new Circle(x, y, radius)`. The mixed circle-vs-rectangle overlap check is provided by `Intersector.overlaps(Circle, Rectangle)`. * Report parse/validation errors via stderr (`System.err.println(...)` or `Gdx.app.error(...)` plus a non-zero exit code from the launcher's `main`). Successful runs must exit with status code `0`.

## Design Highlights

**Main.java** parses `--shapes=<abs_path>` and `--output=<abs_path>` (missing args → exit code 2 and a usage line on stderr), constructs a `HeadlessApplication` with `HeadlessApplicationConfiguration.updatesPerSecond = 0`, hands the listener a `CountDownLatch` + `AtomicInteger`, awaits the latch from the main thread, then calls `System.exit(code)`.

**HeadlessListener.java** extends `ApplicationAdapter` and does all work in `create()`:
- Reads the file via `Gdx.files.absolute(shapesPath)` (BufferedReader for proper CR/LF handling).
- Skips blank/whitespace-only lines and lines starting with `#`.
- For each remaining line: trims, splits on `\s+`, requires token 0 to match `[A-Za-z0-9_-]+` and to be unique (tracking IDs in a `HashSet`).
- Builds `com.badlogic.gdx.math.Rectangle(x, y, w, h)` or `com.badlogic.gdx.math.Circle(x, y, r)` from the numeric tokens; requires `width`, `height`, `radius` to be strictly `> 0` (NaN-safe).
- Computes pairwise overlap with `Rectangle.overlaps(Rectangle)`, `Circle.overlaps(Circle)`, and `Intersector.overlaps(Circle, Rectangle)` — never reimplements geometry by hand.
- For each hit, ensures the lex-smaller id is first via `String.compareTo`, then sorts the pair list lexicographically on `(id_a, id_b)`.
- Writes the report with `Files.write(..., UTF_8)` (overwriting any existing file). Always ends with a single trailing `\n`. Empty input → `total_overlaps=0\n` only.
- Errors:
  - Duplicate id → `Error: duplicate id <id>` (stderr), exit code 1.
  - Malformed line → `Error: invalid shape line: <line>` (verbatim, no newline; via `BufferedReader.readLine()` which strips line terminators), exit code 1.
  - Any other failure → `Error: <msg>`, exit code 1.
