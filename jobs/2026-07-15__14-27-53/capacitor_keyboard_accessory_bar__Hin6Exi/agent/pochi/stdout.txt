## Changes

### `capacitor.config.ts`
Added a `plugins.Keyboard` block using the enum members exported by `@capacitor/keyboard`:
- `resize: KeyboardResize.Body` → `"body"` (shrinks the `body` element when the keyboard appears)
- `style: KeyboardStyle.Dark` → `"DARK"` (forces a dark keyboard appearance)
- `resizeOnFullScreen: true` (enables the Android full-screen resize workaround)

### `src/main.ts`
Registered `window` listeners for all four keyboard events (`keyboardWillShow`, `keyboardDidShow`, `keyboardWillHide`, `keyboardDidHide`):

- **On show**: reads `keyboardHeight` from the event (preferring `event.detail.keyboardHeight`, falling back to the `cordova-plugin-ionic-keyboard` style property directly on the event object), then:
  - sets `--keyboard-offset: ${keyboardHeight}px` on `document.documentElement`
  - adds the `keyboard-open` class to `document.body`
- **On hide**:
  - resets `--keyboard-offset` to `0px`
  - removes the `keyboard-open` class

The composer bar (`#composer`) already consumes `var(--keyboard-offset)` for its `bottom` value, and the `body.keyboard-open #composer` shadow rule is already in `style.css`, so no further style changes are needed. No native plugin APIs are called at runtime — only window events are consumed — so the logic works in both the browser/web shim and on a real Capacitor device.
