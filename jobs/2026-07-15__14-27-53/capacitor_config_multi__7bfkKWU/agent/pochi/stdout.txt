# Environment-Aware Capacitor Config with Conditional `server` Section ## Background A Capacitor v8 app currently ships a single static `capacitor.config.ts` that always points the WebView at a local dev server (`server.url` + `cleartext`) and enables insecure WebView options. Shipping this exact config to production is dangerous: production builds must load the bundled web assets locally, with no external server override and no insecure WebView flags. Your job is to turn the static config into an **environment-aware** TypeScript config that resolves the correct options from `process.env.NODE_ENV` at module load time. The existing (static) config already contains the dev values you must preserve: ```ts import type { CapacitorConfig } from '@capacitor/cli'; const config: CapacitorConfig = { appId: 'com.example.envapp', appName: 'Env Aware App', webDir: 'dist', server: { url: 'http://localhost:5173', cleartext: true, }, android: { allowMixedContent: true, }, }; export default config; ``` ## Requirements * Rewrite `capacitor.config.ts` so the object it default-exports depends on `process.env.NODE_ENV`, evaluated when the module is loaded. * The **development** configuration must keep pointing at the local dev server and keep the insecure-but-dev-only WebView flags enabled. * The **production** configuration must remove the `server` override entirely and must not enable any insecure WebView flags, so the app loads its bundled assets securely. * The shared app identity (`appId`, `appName`, `webDir`) must be identical across both environments. ## Implementation Hints * Keep the file a normal Capacitor config module: it must `export default` a resolved `CapacitorConfig` **object** (not a function or a promise), typed with `CapacitorConfig` from `@capacitor/cli`. * Branch on `process.env.NODE_ENV` while building the object; the value is read once at import time, so evaluating the module under different `NODE_ENV` values must yield different exports. * Project path: /home/user/capacitor-app * Config file: /home/user/capacitor-app/capacitor.config.ts * Hard requirements the exported default object must satisfy: * In **all** environments: `appId` is `com.example.envapp`, `appName` is `Env Aware App`, and `webDir` is `dist`. * When `NODE_ENV` is `development`: `server.url` is `http://localhost:5173`, `server.cleartext` is `true`, and `android.allowMixedContent` is `true`. * When `NODE_ENV` is `production`: the exported object must have **no** `server` property (it must be `undefined`), and it must **not** enable insecure WebView flags (`android.allowMixedContent` must not be `true`; `server.cleartext` must not be `true`). * Any `NODE_ENV` value other than `development` (including when `NODE_ENV` is unset) must resolve to the secure production configuration described above (production/secure is the default).

```ts
import type { CapacitorConfig } from '@capacitor/cli';

const isDevelopment = process.env.NODE_ENV === 'development';

const config: CapacitorConfig = isDevelopment
  ? {
      appId: 'com.example.envapp',
      appName: 'Env Aware App',
      webDir: 'dist',
      server: {
        url: 'http://localhost:5173',
        cleartext: true,
      },
      android: {
        allowMixedContent: true,
      },
    }
  : {
      appId: 'com.example.envapp',
      appName: 'Env Aware App',
      webDir: 'dist',
    };

export default config;
```

**Verified runtime behavior:**

| `NODE_ENV` | `appId` | `appName` | `webDir` | `server` | `android.allowMixedContent` |
|---|---|---|---|---|---|
| `development` | `com.example.envapp` | `Env Aware App` | `dist` | `{ url: 'http://localhost:5173', cleartext: true }` | `true` |
| `production` | `com.example.envapp` | `Env Aware App` | `dist` | `undefined` (key absent) | not set |
| unset | `com.example.envapp` | `Env Aware App` | `dist` | `undefined` (key absent) | not set |

**How it satisfies each requirement:**

- *Module-load evaluation* — `process.env.NODE_ENV` is read once into `isDevelopment` at import time, so the exported `CapacitorConfig` object is fully resolved before any consumer sees it.
- *Default export is a plain `CapacitorConfig` object* — not a function, not a promise; typed via `CapacitorConfig` from `@capacitor/cli`.
- *Dev preserves original behavior* — keeps `server.url: 'http://localhost:5173'`, `server.cleartext: true`, and `android.allowMixedContent: true`.
- *Production strips the insecure surface* — the production object literal has no `server` key at all (so `'server' in config === false` and `config.server === undefined`) and does not enable `android.allowMixedContent`.
- *Secure-by-default* — only the exact string `'development'` takes the dev branch; anything else (including unset) falls through to the secure production config.
- *Shared identity* — `appId`, `appName`, and `webDir` are identical across both branches.
