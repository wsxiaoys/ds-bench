- **Bare Number**: `number` is matched and mapped to `num:<value>`.
- **String Array**: `string[]` is matched and mapped to `list:<length>`.
- **Click Event (Button)**: `kind: 'click'` with `target.type: 'button'` and `id: string` is matched and mapped to `btn:<target.id>`.
- **Click Event (Link)**: `kind: 'click'` with `target.type: 'link'` and a syntactically valid `href` URL (using `"string.url"`) is matched and mapped to `link:<target.href>`.
- **Submit Event**: `kind: 'submit'` with `payload` containing `formId: string` and `valid: boolean` is matched and mapped to `submit:<formId>:<valid>`.
- **Default Rejection**: Configured with `default: "assert"`, throwing a `TraversalError` if none of the cases match.

### 2. TypeScript CLI (`cli.ts`)
The CLI reads a single JSON document of the form `{"events": [...]}` from `stdin`, processes the events in order, and applies the `route` matcher to each.
- Successfully routed events are printed to `stdout` line-by-line in the original input order.
- The first time `route` throws a `TraversalError`, it prints `ERR <message>` to `stdout` and stops processing remaining events.
- The CLI always exits with status code `0`, even when a traversal rejection occurs.
