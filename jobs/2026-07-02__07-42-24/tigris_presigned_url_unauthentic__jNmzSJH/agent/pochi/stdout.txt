# Tigris Presigned URL: Unauthenticated Download via curl ## Background Tigris is a globally distributed, S3-compatible object storage service exposed at the single virtual-hosted-style endpoint `https://t3.storage.dev`. Because Tigris is S3-compatible, you can mint **AWS SigV4 presigned URLs** for it with the standard AWS Python SDK (boto3) via `s3_client.generate_presigned_url("get_object", ...)`. The resulting URL embeds the signature in the query string (`X-Amz-Signature=...`) and can be fetched by *any* HTTP client without authentication headers — that is the entire point of a presigned URL. The Harbor runtime injects the Tigris credentials and endpoint into the container as the AWS-flavored environment variables `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_ENDPOINT_URL_S3` (`https://t3.storage.dev`), and `AWS_REGION` (`auto`) so boto3 picks them up automatically. ## Requirements From the project directory `/home/user/tigris-task`, perform the following steps **in order**: 1.
