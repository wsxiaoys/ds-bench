   - Ranks are mapped as 1-based sequential integers (`1, 2, 3, ...`) with no gaps or duplicates.

3. **Additive Score Updates**:
   - The `POST /api/score` endpoint accepts `player_id` and a signed integer `delta`.
   - It fetches the current score, adds the `delta` to it, and updates the player's document in Typesense using a `PATCH` request.

4. **Concurrency Correctness**:
   - To prevent lost updates from concurrent requests for the same player, the server processes updates inside an in-memory queue (Promise chain) per `player_id`. This guarantees sequential execution and ensures that no updates are lost.

5. **Real-time Live Updates**:
   - The HTML page (`GET /`) renders the leaderboard and provides the score update form.
   - The client polls the `/api/leaderboard` API every 1 second to automatically reflect score updates (including those from other clients) without manual page reloads.

6. **Start Script**:
   - The `start.sh` script automatically starts the Typesense server if it is not already running, waits for it to become healthy, and then starts the Node.js server in the foreground.
