### Implementation Details

1. **Robust Grid-Based Triangulation (`build`):**
   - Collects all unique X and Y coordinates of the boundary and hole vertices.
   - Slices the space into a grid of rectangular cells based on these unique coordinates.
   - For each cell, computes its intersection with the boundary and clips out any overlapping holes using `Geometry2D` clipping functions.
   - Triangulates each resulting simple polygon using `Geometry2D.triangulate_polygon`, filtering out any degenerate triangles (zero/near-zero area) and ensuring a consistent counter-clockwise (CCW) winding order.
   - This grid-based strategy naturally aligns all vertices of adjacent triangles, completely avoiding T-junctions and ensuring a perfectly conforming triangulation.

2. **Adjacency Computation (`get_adjacency`):**
   - Uses a fast $O(T)$ spatial-hashing strategy to merge duplicate vertices within a small tolerance (`1e-4`).
   - Maps each edge to the indices of the triangles sharing it.
   - Two triangles are adjacent if and only if they share a common edge (exactly two vertex indices).
   - Returns the adjacency lists sorted in ascending order.

3. **Centroid-Based Pathfinding (`find_triangle_path`):**
   - Builds an `AStar2D` graph where nodes represent triangle centroids and arcs connect adjacent triangles.
   - Computes path queries over the graph using Euclidean distance between centroids as edge weights and heuristic.
   - Correctly returns a `PackedInt32Array` representing the path of triangle indices, or an empty array if no path exists or either endpoint is outside the walkable region.

4. **Fast Point Location (`triangle_at_point`):**
   - Employs a precomputed bounding-box check for each triangle, followed by a precise `Geometry2D.is_point_in_polygon` check.
   - Correctly handles points inside holes or outside the boundary, returning `-1` for non-walkable coordinates.
