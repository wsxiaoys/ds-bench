# Weighted A\* Grid Pathfinding on the libGDX Headless Backend ## Background Build a command-line pathfinding tool as a **libGDX 1.14.2 headless application**. The program loads a weighted grid map from a text file and computes a minimum-cost route between two cells over an 8-connected weighted grid. It must run entirely under the libGDX *headless* backend (no graphics, audio, or OpenGL). ## Requirements * Read a grid-map file whose path is supplied as the first program argument, compute the minimum-cost path from the start cell to the goal cell, and print the result to standard output in the exact format described below. * The application MUST boot and run as a libGDX headless application (`com.badlogic.gdx.backends.headless.HeadlessApplication`). It MUST NOT perform any OpenGL / graphics / audio work (no `SpriteBatch`, `BitmapFont`, FreeType, or `Gdx.gl*`). * The A\* search **open set / frontier** MUST be a min-priority queue built on top of `com.badlogic.gdx.utils.BinaryHeap`, using a custom subclass of `com.badlogic.gdx.utils.BinaryHeap.Node`. You MUST NOT use `java.util.PriorityQueue`, `java.util.TreeSet`, `java.util.TreeMap`, or any other JDK-provided priority-queue or self-balancing-tree collection as the search frontier. ## Input file format * A plain ASCII text file with the following lines, in order: * Line 1: two integers `R C` separated by a single space (number of rows, number of columns). * Line 2: two integers `sr sc` (start row, start column). * Line 3: two integers `gr gc` (goal row, goal column). * The next `R` lines are the grid, each line containing exactly `C` characters. * Each grid character is either `#` (a wall, impassable) or a digit `1`-`9` (an open cell whose *terrain cost* equals that digit). * Coordinates are 0-based and row-major: cell `(r, c)` is at row `r` (row 0 is the first grid line, counting downward) and column `c` (column 0 is the leftmost character). The start and goal cells are guaranteed to be open (never `#`). ## Movement and cost model * Movement is **8-connected**: the neighbors of a cell are its 4 cardinal (up/down/left/right) and 4 diagonal cells, as long as they stay inside the grid and are not walls. * Let `t(x)` be the terrain cost (the digit) of an open cell `x`. The cost of one move from cell `A` to an adjacent open cell `B` is: * Cardinal move (A and B share an edge): `(t(A) + t(B)) / 2`. * Diagonal move: `sqrt(2) * (t(A) + t(B)) / 2`. * **No corner cutting:** a diagonal move from `A = (r, c)` to `B = (r', c')` (with `r' = r±1`, `c' = c±1`) is permitted only if BOTH orthogonally-adjacent cells `(r, c')` and `(r', c)` are open (non-wall). If either of those two cells is a wall, the diagonal move is forbidden. * The total cost of a path is the sum of its individual move costs. Perform all cost arithmetic using 64-bit double precision. ## Output Write ONLY the following to standard output (stdout), with nothing else on stdout: * If a path from start to goal exists, print exactly these lines in this order: * `LENGTH <k>` where `<k>` is the number of cells in the path, counting both the start and the goal cell. * `COST <c>` where `<c>` is the minimum total path cost formatted with exactly 4 digits after the decimal point using half-up rounding (for example `COST 8.0711`). * `PATH` * then `<k>` lines, each of the form `r,c` (row and column separated by a single comma, no spaces), listing the cells of the path from the start cell to the goal cell inclusive. * If the goal is unreachable from the start, print exactly one line containing `NO PATH` and nothing else. * If more than one distinct path achieves the minimum total cost, output the one that is lexicographically smallest when viewed as its sequence of cells, comparing cell by cell from the start; to compare two cells, compare their row first and then their column. ## Implementation Hints * Project path: `/home/user/gdx-astar`. * The tool is invoked from the project root exactly as: `./gradlew -q run --args="<map_file_path>"`, where `<map_file_path>` is an absolute path to a map file. Running this command MUST read that map file and print the result described in the Output section to stdout, with no other content on stdout. * Pin libGDX to version `1.14.2`. The only external libraries you may use are the libGDX artifacts `com.badlogicgames.gdx:gdx:1.14.2`, `com.badlogicgames.gdx:gdx-backend-headless:1.14.2`, and the desktop natives `com.badlogicgames.gdx:gdx-platform:1.14.2:natives-desktop`. * The environment has NO internet access at test time. These libGDX artifacts and the Gradle 8.10 distribution are already present in the local caches. Do not add any other external or network-fetched dependency.
