This prevents substring matching or matching values from elsewhere in the JSON document.
   - **JSON Key Updates (`set-key`)**: Performs a targeted update utilizing SQLite's native `json_set(attributes, :jsonPath, json(:jsonLiteral))` to set/update a nested JSON path while leaving sibling keys and other branches intact.
