## What it does

1. **Reads** raw JSON lines from `user_events.jsonl` via `FileSource`.
2. **Parses** each line into an event dict, converting the ISO 8601 `timestamp` into an aware UTC `datetime` (stored as `ts`).
3. **Keys** the stream by `user_id` with `op.key_on` so sessions are tracked per user.
4. **Windowing**:
   - `EventClock` with `ts_getter` returning the event's `datetime` (event-time clock).
   - `SessionWindower` with a `gap` of 30 minutes (inactivity gap).
   - `collect_window` gathers all events in each session into a list.
5. **Summarizes** each session with `op.map_value`: sorts events by time, computes `session_start` (first event), `session_end` (last event), and `event_count`, then serializes to a JSON line. `map_value` preserves the keyed-stream structure so the sink can route by key.
6. **Writes** the results to `sessions.jsonl` via `FileSink`.
