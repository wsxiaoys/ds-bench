## How it works

**ArkType `match` with exhaustiveness**: The converter uses `$.match({...})({...})` — the first call defines typed cases (with `default: "assert"`), and the second call dispatches the input data. Named type aliases are defined in a `scope` so they can be used as object keys while still matching full object shapes (`{ kind: "length", meters: "number" }`, etc.).

**`default: "assert"`** ensures exhaustiveness: any input that doesn't match a declared case causes the matcher to throw an error (e.g., `{ kind: "volume", liters: 1 }` → throws).

**STDIN → STDOUT**: Reads a single JSON object from STDIN, dispatches through the matcher, and prints the formatted imperial-unit string to STDOUT.
