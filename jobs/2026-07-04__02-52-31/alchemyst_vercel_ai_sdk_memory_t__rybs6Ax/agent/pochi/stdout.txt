Alchemyst is a Context Engine that gives LLMs durable memory keyed by `(userId, sessionId)`. When `withAlchemyst(...)` wraps `generateText`, every call to the wrapped function REDACTEDmatically (a) retrieves past memories for the `userId`, (b) injects them into the prompt, and (c) persists the new turn. This lets the agent remember a preference established in one session and reuse it in a completely different session for the same user. The CLI must demonstrate this with two phases: - `--phase establish`: the user tells the assistant a personal dietary preference.
