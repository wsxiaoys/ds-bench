Implemented `/home/user/project/shape_transients.py`, a librosa-based command-line transient designer.

**How it works:**
1. Reads the mono input WAV with `soundfile` (preserves exact sample count/rate).
2. Detects percussive transients via `librosa.onset.onset_detect(..., backtrack=True)`, which locates onsets and backtracks each one to the preceding local minimum of the onset-strength envelope, then converts frames→samples.
3. Builds an ideal piecewise-constant target gain array: `attack_gain_db`→linear inside each attack region `[s, s+attack_len)` (capped so it never overlaps the next transient or run past the signal end), and `sustain_gain_db`→linear everywhere else.
4. Finds every value-change boundary in that target array and replaces a `±crossfade_ms` window around each with a raised-cosine (smooth, continuous, click-free) ramp between the two gain values — leaving exact flat plateaus outside the crossfade windows.
5. Multiplies the input by this envelope, clips to `[-1.0, 1.0]` as a safety net (guaranteeing the required output range), and writes the shaped WAV (same length & sample rate as input, float32).
6. Writes the JSON report with `sample_rate`, `num_transients`, global `attack_gain_db`/`sustain_gain_db`, and an ascending-ordered `onsets` array (each with `onset_time`, `attack_gain_db`, `sustain_gain_db`).

**Verified via synthetic test audio** (4 percussive hits with noise transient + tonal body, plus a silence edge case):
- Detected onset times closely match the true hit locations (backtracked slightly earlier, as expected).
- Output length and sample rate exactly match input.
- Gain plateaus in attack/sustain regions match `10**(gain_db/20)` exactly (validated numerically).
- Envelope is continuous everywhere (max per-sample delta stays small/smooth, no jumps).
- `output == input * envelope` bit-for-bit (aside from float32 rounding) except for the handful of samples that would exceed ±1.0, which are safely clipped.
- Silence input (zero onsets) produces an empty `onsets` list and a correctly-sized, unmodified output.
