import numpy as np, soundfile as sf, json
sr=22050
def f(m): return 440.0*2**((m-69)/12)
dur=3.0
n=int(sr*dur)
y=np.zeros(n)
t=np.arange(n)/sr
def add_note(y,p,onset,offset,amp=0.8):
    f0=f(p)
    note=np.zeros(n)
    for h in range(1,8):
        note += (1.0/h)*np.sin(2*np.pi*f0*h*t)
    env=np.zeros(n)
    i0=int(onset*sr); i1=int(offset*sr)
    env[i0:i1]=1.0
    y[:] += amp*note*env
    return y

# note re-onset with a clear 0.25s gap -> should be 2 separate notes

**Template dictionary (W)**: For each MIDI pitch 48–72, deterministically synthesizes a harmonic tone (fundamental + integer harmonics with 1/h amplitude decay, capped below 95% Nyquist), runs it through the exact same STFT (n_fft=2048, hop_length=512) used for analysis, and takes a steady-state interior frame as the L2-normalized template column. Result: `W` has shape `(1025, 25)`.

**Activation estimation (H)**: Computes the mixture's magnitude spectrogram `V`, then solves an independent non-negative least squares problem (`scipy.optimize.nnls`) per frame against the fixed `W`, giving the exact min-norm non-negative solution to `V ≈ W @ H` without ever updating `W`.

**Post-processing**: Normalizes `H` by its global max, applies a relative activation threshold, gates out frames with near-zero spectral energy (silence guard, avoids noise-driven false positives during quiet passages), then applies binary morphological closing (fill ≤2-frame gaps) and opening (remove <3-frame spurious blips) per pitch row to get the clean binary piano-roll.

**Notes**: Extracted as maximal runs of consecutive active frames per pitch row, converted to onset/offset seconds via `frame * hop_length / sr`, and sorted by `(onset_time, pitch)`.
