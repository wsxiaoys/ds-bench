**Behavior**
- Accepts a single required `--question <text>` argument via `argparse`.
- Reads `ALCHEMYST_AI_API_KEY` from the environment (exits 1 with a clear stderr message if missing).
- Reads the run id from `/logs/artifacts/run-id` (stripped, with a safe `"unknown"` fallback) and uses it to make the document's `file_name` unique, avoiding 409 Conflict collisions between concurrent runs.
- On every invocation it:
  1. Ingests a 30-day refund policy document via `client.v1.context.add(...)` with `context_type="resource"`, `source="documentation"`, `scope="internal"`, and `file_name=f"refunds-{run_id}.md"`.
  2. Searches the context engine via `client.v1.context.search(query=..., scope="internal", similarity_threshold=0.5)` and reads `result.contexts`.
- Prints each retrieved chunk's `content` to stdout, prefixed with `--- chunk N ---`. If no contexts come back it prints `No relevant contexts were returned for the question.`

**Usage**
```bash
pip3 install alchemystai
export ALCHEMYST_AI_API_KEY=...
python3 /home/user/myproject/main.py --question "What is your refund policy?"
```
