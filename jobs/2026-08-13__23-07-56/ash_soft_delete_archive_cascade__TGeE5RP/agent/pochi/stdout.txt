# Cascading Soft-Delete, Global Read Scoping and Archive Recovery (Ash Framework v3) ## Background `/home/user/forum` holds a Mix project (OTP app `:forum`) for a discussion-forum backend built on the Ash Framework v3 (`ash 3.31.0`). Content is three levels deep: a post owns comments, and a comment owns reactions. Deleting content in this product is never destructive: removed content stays in storage, stays invisible to ordinary readers, can be inspected by an administrator, and can be recovered later. Recovery has to be *precise* — undoing a deletion must bring back exactly what that deletion removed and must not resurrect content that had already been deleted by an earlier, unrelated operation. The project currently contains only the domain shell and the project configuration.
