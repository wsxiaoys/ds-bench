### How it works

**Startup (idempotent):**
- Creates the `products` collection if it doesn't exist (with fields: `name`, `brand` [faceted], `popularity` [int32], `price` [float])
- Upserts all 20 products from `data/products.jsonl` — safe to restart against an already-populated server

**Search & Grouping:**
- Uses Typesense's `group_by: brand` with `group_limit: 3` and `sort_by: popularity:desc`
- Groups are sorted by max popularity within each group (descending)
- Paginated at the group level: 3 brand groups per page
- Empty query matches all 20 products (5 brands across 2 pages)

**DOM Contract (all verified):**
- `data-testid="search-input"` on the search text input
- `data-testid="group"` with `data-brand` and `data-total` attributes per brand group (max 3 per page)
- `data-testid="item"` with `data-id` on each visible product, sorted by popularity descending
- `data-testid="show-more"` only when `data-total > 3`; clicking it fetches all items for that brand via `/api/brand-items?brand=...` and removes the button
- `data-testid="next-page"`, `data-testid="prev-page"`, `data-testid="page-indicator"` for pagination

**Routes:**
- `GET /` — results page with optional `q` and `page` query params
- `GET /api/brand-items?brand=...` — returns all items for a brand (for "Show more")

Run with `npm start` (listens on `0.0.0.0:3000`).
