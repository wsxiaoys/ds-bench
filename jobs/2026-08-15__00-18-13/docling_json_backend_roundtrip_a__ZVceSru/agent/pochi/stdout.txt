### Design & Implementation Details

1. **Package Architecture**:
   - Created a clean Python module layout with `docaudit/__init__.py` and `docaudit/cli.py`.
   - The tool is fully runnable using the command: `python -m docaudit.cli --input-dir <dir> --out-dir <dir>`.

2. **Parsing & Classification Logic**:
   - Audits only files ending with `.json` directly located in `--input-dir`.
   - Classifies candidates in the exact required order:
     - `malformed_json` — if invalid UTF-8 or non-parsable JSON.
     - `not_an_object` — if parses as JSON but is not a JSON object.
     - `version_mismatch` — if validation fails and the major version component differs from the installed SDK major version (`1` vs `99` for `eta_future_version.json`).
     - `schema_invalid` — if validation fails for other schema reasons (e.g. `epsilon_empty_object.json` or `theta_bad_types.json`).
     - `unreadable` — if ingestion fails for any other reason.
     - `ok` — if directly validated and ingested.

3. **Recovery Mechanism**:
   - For `version_mismatch` candidates, replaces the declared version with the installed Docling document model's schema version (`1.10.0`), attempts ingestion, and if successful, marks the candidate as `recovered = True` with status `version_mismatch`.

4. **Artifact Generation**:
   - `<out-dir>/normalized/<stem>.json`: Emits the ingested document's exported dictionary with sorted keys at every level, 2-space indentation, non-escaped non-ASCII characters, and a single trailing newline.
   - `<out-dir>/markdown/<stem>.md`: Emits the ingested document's Markdown export with stripped trailing newlines and exactly one trailing newline appended.

5. **Stability & Parity Checks**:
   - **Stream Parity**: Compares direct path ingestion against parsing from an in-memory `io.BytesIO` stream of the identical JSON bytes to ensure they yield identical exported dictionaries.
   - **Round-Trip Stability**: Re-ingests the emitted normalized JSON file to verify that the exported dictionary matches the original ingested document's dictionary.

6. **Deterministic Reports**:
   - Produces a deterministic, byte-identical JSON report at `<out-dir>/audit_report.json` with sorted documents array, matching exactly the required schema.

7. **Correct Exit Codes**:
   - `5` if input directory does not exist or holds no candidate.
   - `4` if stream parity or roundtrip stability fails for any successfully ingested candidate.
   - `3` if any candidate fails to ingest directly (excluding successfully recovered ones, which are counted under `failed` since their status is `version_mismatch`).
   - `0` if all candidates are ingested successfully directly with stable round-trips.

All requirements have been met, and testing confirms deterministic, byte-identical, and fully compliant execution.
