import os, filecmp

def are_dirs_identical(dir1, dir2):
    comparison = filecmp.dircmp(dir1, dir2)
    if comparison.left_only or comparison.right_only or comparison.funny_files:
        print('Differences in file list:', comparison.left_only, comparison.right_only)
        return False
    match, mismatch, errors = filecmp.cmpfiles(dir1, dir2, comparison.common_files, shallow=False)
    if mismatch or errors:
        print('Mismatched files:', mismatch, errors)
        return False
    for subdir in comparison.common_dirs:
        if not are_dirs_identical(os.path.join(dir1, subdir), os.path.join(dir2, subdir)):
            return False
    return True

### Implementation Details

1. **CLI Module**: Created the `docaudit` package under `/home/user/project` with `docaudit/__init__.py` and `docaudit/cli.py`.
2. **Command**: Supports executing `python -m docaudit.cli --input-dir <dir> --out-dir <dir>`.
3. **Classification & Recovery**:
   - Classifies every `.json` file in `--input-dir` in the exact order specified: `malformed_json`, `not_an_object`, `version_mismatch`, `schema_invalid`, `unreadable`, and `ok`.
   - Recovers `version_mismatch` candidates by replacing the top-level `version` member with the installed Docling document schema version (`1.10.0`), retrying validation, and treating successfully recovered candidates like `ok` candidates for artifact generation, counts, and parity checks.
4. **Artifact Generation**:
   - `normalized/<stem>.json`: Emits canonical JSON serialized with sorted keys, 2-space indentation, non-ASCII characters kept verbatim, and exactly one trailing newline.
   - `markdown/<stem>.md`: Emits Markdown with all trailing newlines stripped and exactly one trailing newline appended.
5. **Checks & Parity**:
   - **Path-vs-Stream Parity**: Ingests from a file path (using a temp file for recovered candidates) and from an in-memory byte stream, then compares their exported dicts.
   - **Round-Trip Stability**: Re-ingests the emitted normalized JSON artifact and verifies that its exported dict matches the original.
6. **Deterministic Machine-Readable Report**:
   - Emits `<out-dir>/audit_report.json` containing the exact keys and structures defined, sorted by filename.
   - Outputs the final summary line on stdout: `AUDIT total=<total> ok=<ok> recovered=<recovered> failed=<failed>`.
7. **Exit Codes**:
   - `5` when `--input-dir` does not exist or has no candidate files (yielding no stdout or filesystem modifications).
   - `4` if any parity or round-trip stability check fails.
   - `3` if any candidate fails (and no parity/round-trip stability check fails).
   - `0` otherwise.

The CLI has been rigorously tested and is fully self-consistent and deterministic across reruns.
