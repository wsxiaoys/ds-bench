import lancedb
import numpy as np
import hashlib

# Test vector distance computation
def embed(text):
    tokens = __import__('re').findall(r'[a-z0-9]+', text.lower())
    vec = np.zeros(32, dtype=np.float32)
    for token in tokens:
        idx = int(hashlib.md5(token.encode('utf-8')).hexdigest(), 16) % 32
        vec[idx] += 1.0
    norm = np.linalg.norm(vec)
    if norm > 0:
        vec = vec / norm
    return vec

### How it works

**Stage 1 & 2 — LanceDB (`recall_and_distances`)**
- Runs a full-text-search query (`query_type="fts"`, limit 10 000) to collect every matching document's `id`.
- Issues a single vector ANN search with `prefilter=True` and a `WHERE id IN (...)` clause restricted to those candidates, recovering the LanceDB `_distance` (L2) for each one.
- Any candidate not returned by the ANN path (edge case: zero-norm vectors) is back-filled with distance `0.0` so it is never silently dropped.

**Stage 3 — ClickHouse (`enrich`)**  
A single batched query with `doc_id IN (...)` joins two sub-selects:
- **`base`** — `JOIN events ⋈ users` to get `events_in_window` (count), `premium_value_sum` (sumIf tier='premium'), and `p95_value` (`quantileExact(0.95)`).
- **`ph`** — pure `events` aggregation bucketed by `toStartOfHour(ts)` → `max(hour_count)` → `peak_hour_count`.

The two subqueries are joined on `doc_id`. Candidates absent from the result (no events in window) are back-filled with zeros in the fusion step.

**Stage 4 — Fusion (`fuse`)**
```python
score = round(premium_value_sum / (1.0 + vector_distance), 6)
```
Sorted by `score` descending, `doc_id` ascending; truncated to `top`.
