The module `/home/user/myproject/solution.py` is implemented and fully tested. Here is a summary of every design decision:

---

### Schema
A fixed PyArrow schema (`_SCHEMA`) is declared at module level and passed to both `create_table` and every `add` call so LanceDB never infers a different type:

| column | type | notes |
|---|---|---|
| `id` | `int64` | caller-supplied |
| `text` | `utf8` | caller-supplied |
| `vector` | `list<float32>[16]` | fixed-size |
| `deleted` | `bool` | tombstone flag |
| `deleted_at` | `int64` | Unix epoch seconds; `0` = live |

---

### Class `TombstoneStore(table_name, db_path=…)`
- **Constructor** — connects to the local LanceDB directory and either opens an existing table or creates a new empty one with `_SCHEMA`. Multiple concurrent callers using different `table_name` values are fully isolated.

---

### `add_documents(docs)`
Converts each dict to match the schema (typed coercions), builds a `pa.Table` with the fixed schema, and appends with `mode="append"`. The first call populates the table; subsequent calls accumulate rows.

---

### `soft_delete(ids) → int`
Counts how many of the given ids are currently live (`deleted = false`), then issues a single `table.update()` setting `deleted=True` and stamping `deleted_at` with `int(time.time())`. Returns the actual changed count (0 for already-tombstoned or missing ids).

---

### `restore(ids) → int`
Mirrors `soft_delete`: counts currently-tombstoned rows among the given ids, then clears `deleted=False, deleted_at=0`. Returns 0 for already-live or missing ids.

---

### `search(query_vector, k) → List[dict]`
Uses LanceDB's vector query builder with:
- `.metric("l2")` — L2 distance
- `.where("deleted = false", prefilter=True)` — tombstones excluded *before* ANN scoring, not after
- `.select(["id", "text", "_distance"])` — only needed columns
- Python-side sort on `(distance, id)` for deterministic tie-breaking

---

### `gc(older_than_seconds) → int`
1. Computes `cutoff = now − older_than_seconds` and counts rows matching `deleted=true AND deleted_at>0 AND deleted_at<=cutoff`.
2. Calls `table.delete(where_clause)` to hard-delete only aged tombstones; live rows and non-aged tombstones are untouched.
3. Calls `table.compact_files()` — merges data fragments, strictly reducing `num_fragments`.
4. Calls `table.cleanup_old_versions(older_than=timedelta(0), delete_unverified=True)` — prunes the version history, strictly reducing `len(list_versions())`.
5. Returns the number of hard-deleted rows.

All observable guarantees verified by the test suite (fragment count and version history both strictly smaller after `gc`, aged tombstones gone, non-aged tombstones and live rows untouched).
