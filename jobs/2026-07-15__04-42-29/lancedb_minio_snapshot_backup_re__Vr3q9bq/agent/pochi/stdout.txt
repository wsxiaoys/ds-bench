Created `/home/user/myproject/solution.py` with the two required functions. Here's a summary of the design:

**`backup(local_table_path, s3_uri)`**
- Resolves the `*.lance` directory and recursively walks every file with `Path.rglob("*")`.
- Each file is uploaded to S3 as `<prefix>/<relative-path-inside-dataset>`, preserving the entire directory layout (data fragments in `data/`, manifests in `_versions/`, transaction records in `_transactions/`).
- Raises `FileNotFoundError` if the local path doesn't exist, or `RuntimeError` if the directory is empty.

**`restore(s3_uri, new_local_table_path)`**
- Lists all S3 objects under `<prefix>/` via a paginated `list_objects_v2` call.
- Raises `FileNotFoundError` immediately (before creating anything on disk) if the prefix is empty/absent.
- Re-creates the original directory tree by stripping the `<prefix>/` part from each key and writing the file to `<dest>/<relative-path>`, creating parent directories as needed.
- On any download failure, catches the exception, removes the partially-written destination directory with `shutil.rmtree`, and re-raises — so no half-open table is ever left behind.
