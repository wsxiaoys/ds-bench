## What was built

**Script**: `/home/user/altair_chart/generate_chart.py`

The script reads `data/marketing.csv` (180 rows: 60 per region for North, South, West) and builds a single layered Altair chart with four layer types:

1. **Scatter points** — `mark_circle` showing raw `spend` vs. `sales` data, colored by region.
2. **LOESS smoothing line** — `transform_loess('spend', 'sales', groupby=['region'])` rendered as a solid `mark_line` (strokeWidth=3).
3. **Linear regression trend line** — `transform_regression('spend', 'sales', groupby=['region'], method='linear')` rendered as a dashed `mark_line` with `strokeDash=[8, 4]` to visually distinguish it from the LOESS line.
4. **R² text annotation** — A separate `transform_regression(..., params=True)` grouped by region produces one row per region with `rSquared`. A `transform_calculate` formats it as `"R² = " + format(datum.rSquared, ".2f")` (e.g., `R² = 0.80`). The text is positioned near the right edge of each region's regression line using the regression coefficients (`datum.coef[0] + datum.coef[1] * 95`).

## Offline rendering

The HTML was generated using `vl_convert.vegalite_to_html(spec, bundle=True)`, which embeds the Vega, Vega-Lite, and Vega-Embed JavaScript libraries directly in the file. The dataset is embedded inline in the Vega-Lite spec's `datasets` field. The file contains **no CDN references, no CSV path references, and no remote data URLs** — it renders fully offline.
