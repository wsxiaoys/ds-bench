## What was built

**`/home/user/project/build_slope_graph.py`** — a Vega-Altair script that:

1. **Loads** the local CSV (`/home/user/project/data/regional_revenue.csv`) with pandas — no remote fetching.
2. **Derives the trend inside the spec** using a `calculate` transform that compares the two original year columns *before* any reshaping:
   ```
   trend = datum.revenue_2024 > datum.revenue_2023 ? "Increase" : "Decrease"
   ```
   This classification is computed entirely within the chart specification — it is NOT a pre-existing CSV column or a pandas column.
3. **Reshapes** the wide year-columns into two x-positions with a `fold` transform (`revenue_2023` / `revenue_2024` → `year_key` / `revenue`), then a second `calculate` turns the folded key into a clean `"2023"` / `"2024"` year label.
4. **Layers three marks** on a shared transformed base:
   - **line** — one segment per region (a `detail` encoding on `region` keeps each region as its own line even when multiple regions share the same trend colour).
   - **circle** (point) — drawn at both endpoints of every region's line.
   - **text** — labels the revenue value at both endpoints.
5. **Colours** lines and points by the `trend` field (nominal type → two distinct colours: green for Increase, red for Decrease).
6. **Embeds data inline** — the 6-row dataset is stored in the spec's `datasets` key; the only `http(s)` references are the Vega/Vega-Lite/Vega-Embed JS library CDN scripts and the JSON schema URL (no data URLs).
7. **Saves** a self-contained standalone HTML page via `chart.save()`.
