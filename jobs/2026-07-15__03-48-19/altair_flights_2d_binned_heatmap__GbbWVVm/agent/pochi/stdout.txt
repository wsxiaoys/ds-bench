## What the script does

**1. Dataset generation (`generate_flights`)**
- Builds a pandas DataFrame in memory with exactly three columns: `hour` (int 0–23), `day` (categorical `Mon`–`Sun`), and `delay` (numeric minutes, can be negative).
- Populates **every** hour×day combination (24 × 7 = 168 cells) with 40 flights each (6,720 rows total), so the heatmap is fully filled.
- Delay pattern is realistic: baseline grows through the day, weekends (Fri/Sat/Sun) get an extra boost, Gaussian noise, and early (negative) departures.
- `day` is set as an ordered categorical so the y-axis follows calendar order.

**2. Layered chart (`build_chart`)**
- **Layer 1 — `mark_rect` heatmap**: x = binned `hour` (`alt.X('hour:Q').bin(maxbins=24, step=1)`), y = `day`, color = `mean(delay)` with the named scheme `redyellowblue` (and `domainMid=0` so early/late splits at white).
- **Layer 2 — `mark_text` overlay**: same x/y encodings, prints `mean(delay)` formatted to 1 decimal inside each cell, with text color switching to white for high-delay cells for readability.
- Both layers aggregate `delay` with the mean operation so the printed number matches the cell color.
- Axis titles: x = `Departure Hour`, y = `Day of Week`.
- Uses Altair 5 method-based channel syntax (`alt.X(...).bin(...)`, `alt.Color(...).scale(scheme=...)`).

**3. Export**
- `alt.data_transformers.disable_max_rows()` ensures all data is embedded inline.
- `chart.save(...)` writes a self-contained HTML file whose Vega-Lite spec carries the data in an inline `"datasets"` block — **no remote data URL, no `vega_datasets` reference**.
