## How it works

1. **Load data** — reads the bundled CSV (`data/product_sales.csv` with columns `period`, `category`, `sales`).

2. **Declarative ranking via window transform** — instead of pre-computing ranks in pandas, the ranking is computed inside the chart spec:
   ```python
   .transform_window(
       rank="rank()",
       sort=[alt.SortField(field="sales", order="descending")],
       groupby=["period"],
   )
   ```
   This groups by `period`, sorts by `sales` descending, and outputs the result into a field named exactly `rank` (highest sales = rank 1).

3. **Layered chart** — a shared `base` chart (data + transform + encodings) is reused for two marks:
   - `mark_line` → connected series for each product line
   - `mark_point` → marker at every period
   
   They are combined with `line + point` into a single layered spec.

4. **Encodings** — `period` on x, `rank` on y with `scale=alt.Scale(reverse=True)` so rank 1 sits at the top, and `category` on color.

5. **Tooltip** — exposes `category`, `period`, `rank`, and `sales` for each marker.

6. **Export** — `chart.save(...)` produces a standalone HTML document containing the Vega-Lite spec and loading the Vega/Vega-Lite runtime; all 30 data rows are embedded inline via Altair's `datasets` mechanism (the spec references a *named* inline dataset, not a remote URL).
