## How it works
The script loads the local `data/sales.csv`, then composes one Altair chart from two vertically concatenated (`&`) views that share a single selection:

1. **Shared interactive legend selection**
   ```python
   sel = alt.selection_point(fields=["category"], bind="legend", name="category_sel")
   ```
   A point selection projected on `category` and bound to the legend. It is added to both views, so one legend controls the entire dashboard.

2. **Stacked bar view** — `yearmonth(date)` × `sum(sales)`, colored by `category`, with a conditional opacity encoding:
   ```python
   opacity=alt.condition(sel, alt.value(1), alt.value(0.2))
   ```
   The selected category is fully opaque; non-selected categories are dimmed. (When nothing is selected, the empty-selection default makes all bars fully opaque.)

3. **Time-series line view** — one line per `category` over `yearmonth(date)` × `sum(sales)`, narrowed by a filter transform driven by the same selection:
   ```python
   .transform_filter(sel)
   ```
   Only the selected category's line is shown; when nothing is selected all lines are shown. Its color legend is suppressed (`legend=None`) so the dashboard has a single legend.

4. **Self-contained output** — saved with `dashboard.save(..., format="html", inline=True)`, which uses `vl-convert-python` to inline the Vega/Vega-Lite/vega-embed runtime and embed the full dataset inline.
