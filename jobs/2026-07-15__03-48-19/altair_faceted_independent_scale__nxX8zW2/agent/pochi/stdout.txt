import altair as alt, pandas as pd
df=pd.read_csv('metrics.csv')
hover=alt.selection_point(nearest=True,on='pointerover',fields=['date'],empty=False)
base=alt.Chart(df).encode(x='date:T',y='value:Q',color=alt.Color('series:N',legend=alt.Legend(title='Series')),tooltip=[alt.Tooltip('date:T'),alt.Tooltip('value:Q')])
lines=base.mark_line()
points=base.mark_circle().encode(opacity=alt.condition(hover,alt.value(1.0),alt.value(0.0))).add_params(hover)
chart=((lines+points)).facet(column=alt.Column('series:N'),columns=2).resolve_scale(y='independent')

## What was created

**`/home/user/project/build_chart.py`** — A script that:
1. Reads the long-form CSV with pandas (`date`, `series`, `value`), so Altair infers column types.
2. Defines a **single shared point selection** (`alt.selection_point` with `nearest=True`, `on="pointerover"`, `fields=["date"]`) and adds it to the inner (pre-facet) points layer — so one shared parameter drives the hover in every panel rather than being duplicated per facet.
3. Builds a base encoding with `x=date:T` (temporal), `y=value:Q` (quantitative), `color=series:N` (nominal, with a single legend), and a `tooltip=[date, value]`.
4. Layers the line mark over an invisible-by-default circle mark that becomes opaque at the nearest point under the pointer (carrying the tooltip + selection).
5. Facets with the single-field facet form `column=alt.Column("series:N")` together with `columns=2`, producing a wrapped **2×2 grid** for the four series.
6. Applies `.resolve_scale(y="independent")` so each panel uses its own y-scale while leaving the color scale **shared** (the default resolution), keeping one consistent color mapping and a single legend.
7. Saves the chart with `chart.save()` as a complete standalone HTML document that embeds the full Vega-Lite spec and the data inline (no external data source).

**`/home/user/project/chart.html`** — The output (run via `python3 build_chart.py`).
