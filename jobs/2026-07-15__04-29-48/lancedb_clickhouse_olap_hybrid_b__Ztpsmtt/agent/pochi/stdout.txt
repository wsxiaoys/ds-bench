import clickhouse_connect
client = clickhouse_connect.get_client(host='localhost', port=8123, username='default', password='')

ch_query = '''
SELECT
  base.doc_id,
  base.events_in_window,
  base.premium_value_sum,
  base.p95_value,
  coalesce(hc.peak_hour_count, 0) AS peak_hour_count
FROM (
  SELECT
    e.doc_id AS doc_id,
    count() AS events_in_window,
    sumIf(e.value, u.tier = \\'premium\\') AS premium_value_sum,
    quantileExact(0.95)(e.value) AS p95_value
  FROM events AS e
  LEFT JOIN users AS u ON e.user_id = u.user_id
  WHERE e.doc_id IN {ids:Array(Int64)}
    AND e.ts >= {start:DateTime}
    AND e.ts < {end:DateTime}
  GROUP BY e.doc_id
) AS base
LEFT JOIN (
  SELECT doc_id, max(cnt) AS peak_hour_count
  FROM (
    SELECT doc_id, toStartOfHour(ts) AS hour_bucket, count() AS cnt
    FROM events
    WHERE doc_id IN {ids:Array(Int64)}
      AND ts >= {start:DateTime}
      AND ts < {end:DateTime}
    GROUP BY doc_id, hour_bucket
  )
  GROUP BY doc_id
) AS hc ON base.doc_id = hc.doc_id
ORDER BY base.doc_id
'''

    tokens = re.findall(r'[a-z0-9]+', text.lower())

## How it works

The script reads a JSON query file and executes a 4-stage pipeline:

### 1. Recall (LanceDB FTS)
Performs a full-text-search (`query_type="fts"`) against the `documents` table with a limit equal to `count_rows()` to retrieve **all** documents with a positive FTS match. The candidate set is collected as a set of `id`s.

### 2. Vector Distance (LanceDB)
Embeds the query text using the exact deterministic hashing bag-of-words scheme (md5 `% 32`, L2-normalize, float32). Then runs a LanceDB vector search (`query_type="vector"`) with a `.where("id IN (...)")` prefilter restricted to the candidate IDs, collecting the `_distance` field for every candidate.

### 3. Enrichment (ClickHouse)
A single batched parameterized query with `doc_id IN {ids:Array(Int64)}` restricted to the half-open time window computes:
- `events_in_window` — `count()` of all events
- `premium_value_sum` — `sumIf(value, tier='premium')` via LEFT JOIN to `users`
- `p95_value` — `quantileExact(0.95)(value)`
- `peak_hour_count` — `max()` of per-hour counts bucketed by `toStartOfHour(ts)`

Candidates with no events in the window are **back-filled with zeros** (82 of 374 candidates for the sample query).

### 4. Fusion & Ordering
`score = premium_value_sum / (1.0 + vector_distance)`, rounded to 6 decimal places. Results are sorted by `score` descending, then `doc_id` ascending, truncated to `top`.
