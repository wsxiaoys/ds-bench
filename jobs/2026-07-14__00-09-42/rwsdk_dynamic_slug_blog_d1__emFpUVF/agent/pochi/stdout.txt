A base RedwoodSDK project has already been scaffolded for you. ## How It Works

- **Database access** uses `import { env } from "cloudflare:workers"` to access the D1 binding, then `drizzle(env.DB)` to create the ORM client — no need to thread `env` through props.
- **`/blog`** — `BlogIndex` fetches all rows and renders `<a href="/blog/{slug}">{title}</a>` for each post.
- **`/blog/:slug`** — the route handler calls `BlogPost({ slug: params.slug })`; if the component returns `null` (no DB row found) it short-circuits to `new Response("Post not found", { status: 404 })`, otherwise returns the JSX directly.
- The migration was applied to the local D1 instance and two sample posts were seeded for testing.
