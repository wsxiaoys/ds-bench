Request body (JSON): ```json { "name": string, "email": string } ``` * On success returns status `201` with the created user as JSON: `{ "id": number, "name": string, "email": string }`. * If `name` or `email` is missing or empty, returns status `400`. * If a user with the same `email` already exists, returns status `409`.
