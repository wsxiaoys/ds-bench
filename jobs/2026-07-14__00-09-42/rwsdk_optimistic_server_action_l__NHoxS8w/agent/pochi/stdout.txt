## How it works
1. On page load, `Home` (Server Component) queries `SELECT * FROM likes WHERE id = 1` and passes `count` to `LikeButton`.
2. Clicking "👍 Like" calls the `serverAction`, which does an `INSERT ... ON CONFLICT DO UPDATE SET count = count + 1`.
3. RedwoodSDK's `serverAction` wrapper automatically triggers a re-render of the page after the action, so the displayed count updates without a manual reload.
4. The count persists across reloads because it's stored in the Cloudflare D1 database.
