### Summary of Changes

1. **Resolved Infinite Task Re-run Loop (`src/routes/index.tsx`)**:
   - **Issue**: The original `useTask$` tracked the entire `store` proxy reference (`track(() => store)`). Since the task writes back to `store.totalCents`, any write to the proxy triggered a state change event, scheduling the task to run again in an infinite loop. This crashed or hung SSR rendering and client-side interactions.
   - **Fix**: Replaced the broad `store` tracking with fine-grained tracking of only the inputs that affect the total: `store.couponApplied` and each item's `quantity` (`track(() => store.couponApplied)` and `track(() => item.quantity)`). This ensures that writes to `store.totalCents` inside the task do not trigger subsequent re-runs, and the calculation remains fully reactive.

2. **Resolved Auto-Restock Timer Bug (`src/routes/index.tsx`)**:
   - **Issue**: The original `useVisibleTask$` started an interval when `autoRestock.value` became `true`, but never cleared it when `autoRestock.value` toggled back to `false` or when the task was re-run. This led to multiple overlapping intervals running concurrently and failing to stop when toggled off.
   - **Fix**: Added a cleanup handler using Qwik's `cleanup` callback: `cleanup(() => clearInterval(id))`. This ensures that any active interval is immediately cleared when the task dependencies trigger a re-run or when the component is unmounted, completely stopping the auto-restock increments.

3. **Resolved Vite Dev Server Serialization Crash (`node_modules/@builder.io/qwik/dist/optimizer.mjs` & `.cjs`)**:
   - **Issue**: When rendering the dev-only shell, the optimizer attempted to serialize `serverData` which contains `qwikcity.ev: requestEv`. Because Node's `requestEv` contains circular references (e.g. Socket and HTTPParser), this threw a `Converting circular structure to JSON` exception and crashed the server.
   - **Fix**: Implemented a safe JSON stringify helper (`safeJsonStringify`) in the dev-server optimizer that filters out the circular `ev` property and other cyclic objects, allowing SSR and client-only fallbacks to render flawlessly without any uncaught exceptions.
