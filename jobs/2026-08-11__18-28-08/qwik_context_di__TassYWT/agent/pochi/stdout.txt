Instead of drilling props, the shared state must be injected with Qwik's context API and consumed by components several levels deep. The aggregates must stay correct after every mutation. - Mutations to the cart must be performed by deeply nested child components through the injected cart store (not by lifting handlers to the provider and passing them down as props). Qwik's fine-grained reactivity must update only the DOM nodes bound to the changed state. - The application must be **server-side rendered**: the initial HTML returned by the server (before any client JavaScript runs) must already contain the fully rendered deep tree with the context-derived values.
