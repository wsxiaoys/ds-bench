The integer **window index** of a window is the number of whole 60-second intervals between the alignment instant and the window's start (the window covering `[00:00:00, 00:01:00)` is index `0`, the next is `1`, and so on). ### Implementation Details:
- **Stage 1 (Event-Time Tumbling Window Aggregation)**:
  - Events are ingested line-by-line using Bytewax's `FileSource`.
  - An `EventClock` extracts timestamps from the `ts` field of each event.
  - A `TumblingWindower` with a duration of `60 seconds` is aligned to the instant `2024-01-01T00:00:00+00:00`.
  - Window indices are calculated as integer offsets from the alignment instant.
  - `fold_window` is used to aggregate event counts per item, per window.

- **Stage 2 (Stateful Cascading Computation)**:
  - Maintains a rolling history of the most recent `N = 3` window results per item using `stateful_map`.
  - **Trending Feed**: Computes the growth of each window result compared to the immediately preceding non-empty window result. If the growth is strictly greater than 5, a trending event is emitted to `out/trending.jsonl` using a `FileSink`.
  - **Global Top-K Feed**: Aggregates the final rolling total (sum of counts in up to `N = 3` most recent window results) for each item using `fold_final`. Sorts items by rolling total descending (with ties broken by item name ascending) and writes the top `K = 3` items to `out/topk.jsonl` using a `FileSink`.
