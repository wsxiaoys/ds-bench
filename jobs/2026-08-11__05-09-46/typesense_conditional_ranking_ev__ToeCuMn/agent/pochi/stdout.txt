### 3. Ranking Policy Implementation
The query entrypoint `rank.py` accepts `--query "<q>"` and implements the exact ranking policy using Typesense search parameters:
- **Promotion Tier First:** We use Typesense's `_eval` scoring operator inside `sort_by` to assign scores to each promotion tier:
  `_eval([ (badge:=sponsored):2, (badge:=featured):1 ]):desc`
  This scores `sponsored` as `2`, `featured` as `1`, and `none` as `0`, dominating any text relevance score.
- **Text Relevance Within a Tier:** By setting `text_match_type: "sum_score"`, Typesense sums the text match scores across both the `title` and `description` fields. This rewards documents matching the query in both fields over those matching in only one field.
- **Popularity Tiebreaker:** We append `popularity:desc` as the final tiebreaker in the `sort_by` sequence.

The final `sort_by` parameter is:
`_eval([ (badge:=sponsored):2, (badge:=featured):1 ]):desc,_text_match:desc,popularity:desc`
