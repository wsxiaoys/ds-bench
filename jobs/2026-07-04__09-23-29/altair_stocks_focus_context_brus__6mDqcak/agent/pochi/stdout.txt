## How It Works

1. **Data source**: Uses `data.sp500.url` from `vega_datasets` (URL-based source with explicit type shorthands `date:T` and `price:Q`).

2. **Shared base chart**: A common `alt.Chart(data.sp500.url).mark_area().encode(x='date:T', y='price:Q')` is reused across both views.

3. **Interval brush**: Created with `alt.selection_interval(encodings=['x'])` — a single selection limited to the x (time) axis.

4. **Upper detail (focus) view** (width 600, height 250): `mark_area` encoding `date:T` → `price:Q`, with the x-scale `domain` bound to the brush selection (`alt.Scale(domain=brush)`). This makes the focus view dynamically rescale its x-axis to the brushed time window.

5. **Lower overview (context) view** (width 600, height 70): same `mark_area` over the same data, with the brush attached via `add_params(brush)` so the user can drag the interval on this chart.

6. **Composition**: The two views are vertically concatenated with `alt.vconcat(detail, overview)` — focus on top, context on bottom.

7. **Export**: `chart.save('/home/user/myproject/chart.html')` writes a self-contained HTML file that embeds the Vega-Lite spec and renders it with `vegaEmbed`, preserving the interactive linked brushing behavior.
