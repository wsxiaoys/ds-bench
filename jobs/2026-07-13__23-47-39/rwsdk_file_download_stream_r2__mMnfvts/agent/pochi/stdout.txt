### 2. `src/app/pages/files/files.ts` — download route (new file)
- **Lazy seeding**: `ensureSeedObject()` checks the bucket with `head()` and `put()`s the fixture (`alphabet.txt` → the 26 lowercase letters, `Content-Type: text/plain`) only if missing. This runs inside the request lifecycle since workers can't do I/O at module top level.
- **Range parsing**: `parseRange()` handles all three forms — `bytes=start-end`, `bytes=start-`, and `bytes=-suffix` — and validates them against the object size.
- **`GET /files/:key`**:
  - No `Range` header + key exists → `200` with the full streamed `body`, `Accept-Ranges: bytes`, and `Content-Length` = object size.
  - Valid `Range` + key exists → `206` streaming only the requested bytes via R2's `get(key, { range })`, with `Accept-Ranges: bytes`, `Content-Range: bytes <start>-<end>/<total>`, and `Content-Length` = partial body length. The resolved range is read back from the R2 object to build an accurate `Content-Range`.
  - Missing key → `404`.
  - Malformed/unsatisfiable range → `416` with `Content-Range: bytes */<total>`.
- The body is passed directly as a `ReadableStream` to the `Response` constructor (no buffering).
