## How it satisfies every requirement

| Requirement | How it's met |
|---|---|
| Read local CSV, no remote dataset | `pd.read_csv('/home/user/project/data/cash_flow.csv')` then `alt.Chart(df)`; the data is embedded in the chart's `datasets` and never referenced via URL. |
| Single waterfall chart, one floating bar per row | `mark_bar()` with `y` + `y2` encoding. |
| Preserve row order on x-axis | The original order is pinned via `df.reset_index()` → `row_index`, a Python-side `label_order` list, and `alt.X(..., sort=label_order)`. No alphabetical re-sort. |
| **Window transform** for running cumulative sum | `transform_window(cumulative='sum(amount)', sort=[{'field':'row_index','order':'ascending'}])`. |
| **Calculate transforms** for `y` and `y2` | `transform_calculate(y_start="datum.label === 'End' ? 0 : datum.cumulative - datum.amount")` and `transform_calculate(y_end='datum.cumulative')`. |
| `End` row is total bar from 0 to grand total | Conditional in `y_start` (→ 0) and `y_end = datum.cumulative` (→ 4400, the sum of all amounts). |
| Three visually distinct colors | `transform_calculate(category=...)` maps rows to `increase`/`decrease`/`total`; `alt.Scale` with `range=['#2ca02c','#d62728','#7f7f7f']` (green / red / neutral gray). |
| Text mark labels of each step's delta | A second `mark_text` layer, anchored at `y=y2`, showing the amount via `format=',.0f'`; the `End` row shows the grand total. |
| Single layered Altair chart exported to HTML | `alt.layer(bars, text).save(OUT_PATH, format='html')`. |
