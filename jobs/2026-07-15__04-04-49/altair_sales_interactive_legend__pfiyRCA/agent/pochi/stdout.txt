class Checker(HTMLParser):
    def __init__(self):
        super().__init__(convert_charrefs=True)
        self.stack = []
        self.errors = []
    def handle_starttag(self, tag, attrs):
        # skip self-closing void elements
        if tag not in ('meta', 'link', 'img', 'br', 'hr', 'input', 'source'):
            self.stack.append(tag)
    def handle_endtag(self, tag):
        if self.stack and self.stack[-1] == tag:
            self.stack.pop()
        else:
            self.errors.append(f"mismatched close </{tag}> at line {self.getpos()}")

### How the dashboard satisfies every requirement

**1. Locally-loaded dataset, no remote fetch**

* `pandas.read_csv("/home/user/project/data/sales.csv")` — no network call.
* Altair's inline data transformer inlines the 48 rows (4 categories × 12 months) into `spec.datasets` so the HTML never references `sales.csv` or any `http(s)://…` data URL.
* Final verification reported **zero** remote-loading `<script>`/`<link>`/`<iframe>`/`<img>`/`<source>` tags and **zero** programmatic remote URL assignments in the file.

**2. One combined Altair chart with two vertically-stacked views**

`build_dashboard()` returns a single `alt.vconcat(bar_view, line_view, …)` chart. Both children share the same selection parameter, so a single legend controls the whole dashboard.

**3. Single shared legend-bound point selection**

```python
category_selection = alt.selection_point(
    fields=["category"],
    bind="legend",
    name="category_selection",
)
```

The param is attached to the bar view via `.add_params(category_selection)`, then reused in:

* the **opacity conditional** on the bar view, and
* the **transform_filter** on the line view.

The compiled Vega spec contains the standard legend-driving signals (`category_selection`, `category_selection_tuple`, `category_selection_store`, `category_selection_category_legend`), confirming the legend is genuinely interactive end-to-end.

**4. Bar view — stacked monthly sales by category, dim non-selected**

* `mark_bar()`
* `x="yearmonth(date):T"`
* `y="sum(sales):Q"` (stacked quantitative encoding, axes auto-stacked because of `stack=True` default in the categorical color)
* `color="category:N"` with a custom legend titled *"Product category (click)"*
* `opacity=alt.condition(category_selection, alt.value(1.0), alt.value(0.18))` — full opacity on the selected category, dimmed (`0.18`) for the others.

**5. Line view — monthly trend per category, filter on selection**

* `mark_line(point=True, strokeWidth=2.5)`
* `transform_filter(category_selection)` — when nothing is selected, the filter is a no-op and all four lines render; once a category is clicked via the legend, the transform hides the other three.
* `x="yearmonth(date):T"`, `y="sales:Q"`, `color="category:N"`.

**6. Single self-contained, network-free HTML file**

`chart.save(format="html", inline=True)` uses Altair's `INLINE_HTML_TEMPLATE` together with `vl_convert.javascript_bundle(...)`, which produces a fully inlined vega-embed (with Vega and Vega-Lite bundled inside). The dataset is also embedded via Altair's default `dict/dataframe` inlining, yielding a single 904 KB HTML file that renders offline with no requests.
