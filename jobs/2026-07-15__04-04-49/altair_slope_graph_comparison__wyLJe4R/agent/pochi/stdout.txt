# Slope Graph Comparing Regional Revenue Across Two Years (Vega-Altair) ## Background You are building a static analytics report with https://altair-viz.github.io/. Management wants a *slope graph* that shows, for every sales region, how annual revenue moved from 2023 to 2024. A slope graph plots two x positions (the two years) and draws one line per category (region) connecting its value in each year, so the slope of the line instantly communicates growth or decline. All work is offline. **Files**
- `/home/user/project/build_slope_graph.py` — build script.
- `/home/user/project/slope_graph.html` — standalone HTML chart (3.8 KB), produced by running `python3 /home/user/project/build_slope_graph.py`.

**How the spec satisfies each requirement**

1. **Layered composition of three marks** — `line + point + text` is added to a layered chart.
2. **Line draws one line per region** — the line mark uses `detail=alt.Detail("region:N")` so each region is rendered as its own line segment (regions never share a path even when they share a trend color).
3. **Point mark at both endpoints** — the `point` layer shares the folded data and is drawn at the same `(year_column, revenue)` coordinates as the line endpoints.
4. **Text labels the revenue at both endpoints** — the `text` layer encodes `text=alt.Text("revenue:Q", format=".1f")` at the same coordinates; its `align` and `dx` are conditional expressions so 2023 labels sit to the left of their point and 2024 labels to the right.
5. **Up/down classification is derived *inside* the spec** — the chart opens with
   ```python
   .transform_calculate(
       trend="datum.revenue_2024 > datum.revenue_2023 ? 'increase' : 'decrease'",
   )
   ```
   The `trend` field is added by a `calculate` transform; the input CSV is never mutated and no pandas column is added for it.
6. **Color encoded by trend with nominal type** — `color=alt.Color("trend:N", ...)` in every layer, with a fixed two-color scale (`#1f77b4` for increase, `#d62728` for decrease).
7. **Reshaping with `fold` so the original year columns are visible to `calculate`** — the calculate runs first, then `.transform_fold(fold=["revenue_2023", "revenue_2024"], as_=["year_column", "revenue"])` produces the two x positions.
8. **Data is local and embedded** — `chart.save(...)` emits a self-contained HTML page whose `datasets` block contains all six rows inline; the top-level `data` block references it by name only, and there are no `http`/`https` data URLs anywhere in the spec.
9. **Standalone HTML output** — saved via Altair's HTML export (with the Vega-Lite spec inlined in the page), so opening the file directly in a browser renders the chart.

The script was executed successfully, the chart was validated programmatically against every requirement, and a headless PNG render confirmed the spec compiles end-to-end.
