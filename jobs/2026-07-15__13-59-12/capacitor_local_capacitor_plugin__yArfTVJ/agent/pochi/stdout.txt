## Key implementation details

- **`src/definitions.ts`** — declares the `StringKitPlugin` interface with `echo`, `reverse`, and `slugify` async method signatures, plus their options/result types.
- **`src/web.ts`** — `StringKitWeb extends WebPlugin` and implements all three methods:
  - `echo` returns the input unchanged.
  - `reverse` splits, reverses, and joins (e.g. `"abcde"` → `"edcba"`).
  - `slugify` lowercases, replaces runs of non-`[a-z0-9]` chars with a single hyphen, then trims leading/trailing hyphens (e.g. `"  Hello, World! 123 "` → `"hello-world-123"`).
- **`src/index.ts`** — registers the plugin under the name `StringKit` via `registerPlugin`, lazy-loading the web implementation with `async () => import('./web')`, and `export * from './definitions'`.
- **`package.json`** — sets `"main": "dist/plugin.cjs.js"`, `"module": "dist/esm/index.js"`, `"types": "dist/esm/index.d.ts"`. The `build` script runs `clean → tsc → rollup` in one command. `@capacitor/core` is declared as a peer dependency and marked external in Rollup (confirmed it is `require()`'d, not bundled).
