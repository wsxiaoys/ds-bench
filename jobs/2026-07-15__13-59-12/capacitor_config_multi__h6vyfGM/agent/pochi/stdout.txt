# Environment-Aware Capacitor Config with Conditional `server` Section ## Background A Capacitor v8 app currently ships a single static `capacitor.config.ts` that always points the WebView at a local dev server (`server.url` + `cleartext`) and enables insecure WebView options. Shipping this exact config to production is dangerous: production builds must load the bundled web assets locally, with no external server override and no insecure WebView flags. Your job is to turn the static config into an **environment-aware** TypeScript config that resolves the correct options from `process.env.NODE_ENV` at module load time. The existing (static) config already contains the dev values you must preserve: ```ts import type { CapacitorConfig } from '@capacitor/cli'; const config: CapacitorConfig = { appId: 'com.example.envapp', appName: 'Env Aware App', webDir: 'dist', server: { url: 'http://localhost:5173', cleartext: true, }, android: { allowMixedContent: true, }, }; export default config; ``` ## Requirements * Rewrite `capacitor.config.ts` so the object it default-exports depends on `process.env.NODE_ENV`, evaluated when the module is loaded. * The **development** configuration must keep pointing at the local dev server and keep the insecure-but-dev-only WebView flags enabled. * The **production** configuration must remove the `server` override entirely and must not enable any insecure WebView flags, so the app loads its bundled assets securely. * The shared app identity (`appId`, `appName`, `webDir`) must be identical across both environments. ## Implementation Hints * Keep the file a normal Capacitor config module: it must `export default` a resolved `CapacitorConfig` **object** (not a function or a promise), typed with `CapacitorConfig` from `@capacitor/cli`. * Branch on `process.env.NODE_ENV` while building the object; How it satisfies the requirements:

- **Shared identity** (`appId`, `appName`, `webDir`) is declared once and present in all environments.
- **Development** (`NODE_ENV === 'development'`): spreads in `server.url: 'http://localhost:5173'`, `server.cleartext: true`, and `android.allowMixedContent: true`.
- **Production / default** (any other `NODE_ENV`, including unset): the conditional spread resolves to `{}`, so the exported object has no `server` property and no insecure WebView flags.
- The module still `export default`s a single resolved `CapacitorConfig` object (not a function/promise), typed with `CapacitorConfig` from `@capacitor/cli`.

```ts
import type { CapacitorConfig } from '@capacitor/cli';

const isDevelopment = process.env.NODE_ENV === 'development';

const config: CapacitorConfig = {
  appId: 'com.example.envapp',
  appName: 'Env Aware App',
  webDir: 'dist',
  ...(isDevelopment
    ? {
        server: {
          url: 'http://localhost:5173',
          cleartext: true,
        },
        android: {
          allowMixedContent: true,
        },
      }
    : {}),
};

export default config;
```
