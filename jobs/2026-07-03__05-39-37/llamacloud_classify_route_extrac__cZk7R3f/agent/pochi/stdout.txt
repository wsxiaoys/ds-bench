`/home/user/myproject/src/index.ts` — runnable via `npm start` (tsx).

### Phase 1 — Upload + Classify
- Reads the run id from `/logs/artifacts/run-id` (`zrbvjz1ghl`).
- Uploads all four PDFs from `inputs/` with `fs.createReadStream`, tagging each with `external_file_id = <run-id>-<basename_without_ext>` (e.g. `zrbvjz1ghl-acme_invoice`).
- Uploads are **idempotent**: before uploading, it lists files by `external_file_id` and reuses the existing file id if present (the API enforces a unique constraint on `external_file_id`, so a naive re-upload would 400). This makes the script safe to re-run.
- Runs a **single** Classify job over all four file ids with `client.classifier.classify({ file_ids, rules, mode: 'FAST' })` and two rules (`invoice`, `contract`).
- Indexes the returned `items` by `file_id` (not array position — items arrive in a different order than the input).

### Phase 2 — Per-category Extract (concurrent, cap 2)
- For each classified file, picks the schema dictated by its category and runs an Extract job with a flattened `configuration: { data_schema, extraction_target: 'per_doc', tier: 'agentic' }`.
- Schemas are defined in **Zod** and converted to JSON Schema via `z.toJSONSchema(schema, "draft-2020-12")`.
  - `invoice`: `invoice_number`, `vendor_name`, `total_amount` (number), `line_items` (array of `{description, quantity, unit_price, total}`).
  - `contract`: `parties` (array of strings, min 2), `effective_date`, `term`.
- The four Extract jobs run **concurrently** via `Promise.all` with a `p-limit(2)` concurrency cap.
- Completion is polled explicitly with `client.extract.get(jobId)` until status is `COMPLETED`/`FAILED`/`CANCELLED`.
- The same uploaded file id is reused for Extract (no re-upload per phase).

### Artifacts written
- `/home/user/myproject/outputs/results.json` — keyed by input basename, each value has exactly `category`, `confidence` (number), `file_id`, `data` (the `extract_result` payload).
- `/home/user/myproject/output.log` — one summary line per file in the required format: `Routed: <basename>.pdf | category: <invoice|contract> | confidence: <conf> | fields: <N>` (4 for invoices, 3 for contracts).
