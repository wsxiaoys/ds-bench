6. Table name is namespaced with the run-id from `/logs/artifacts/run-id` (e.g. `pdf_chunks_zrzh4tcr81`)
7. Idempotent: re-running drops and recreates the same table without erroring

**Search (`search(query, k)`):**
- Embeds the query with the same model
- Returns top-`k` chunks as a list of dicts ordered by descending relevance
- Each dict has `doc_id` (str), `page` (int), `snippet` (str — 200-char excerpt)
