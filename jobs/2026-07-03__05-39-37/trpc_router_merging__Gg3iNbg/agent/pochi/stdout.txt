## Changes Made

### 1. `src/server/routers/_app.ts`
Created the merged root router by importing `router` from `../trpc` and both sub-routers, then composing them under the `user` and `post` namespaces:
```ts
import { router } from '../trpc';
import { userRouter } from './user';
import { postRouter } from './post';

export const appRouter = router({
  user: userRouter,
  post: postRouter,
});

export type AppRouter = typeof appRouter;
```

### 2. `src/app/api/trpc/[trpc]/route.ts`
Imported `appRouter` and passed it to `fetchRequestHandler` (replacing the `{} as any` placeholder):
```ts
import { fetchRequestHandler } from '@trpc/server/adapters/fetch';
import { appRouter } from '../../../../server/routers/_app';

const handler = (req: Request) =>
  fetchRequestHandler({
    endpoint: '/api/trpc',
    req,
    router: appRouter,
    createContext: () => ({}),
  });

export { handler as GET, handler as POST };
```

A relative import path was used because the project's `tsconfig.json` does not configure the `@/` path alias.
