## What the script does

1. **Defines a Zod schema** for the invoice with the required fields: `invoice_number`, `invoice_date`, `vendor_name`, `total_amount`, and a `line_items` array (each with `description`, `quantity`, `unit_price`, `total`).
2. **Converts the schema to JSON Schema** via `z.toJSONSchema(invoiceSchema)` — no hand-written JSON Schema.
3. **Uploads `invoice.pdf`** to LlamaCloud using `client.files.create({ file, purpose: "extract" })` with the SDK's `toFile` helper.
4. **Creates an Extract v2 job** via `client.extract.create({ file_input, configuration: { data_schema, extraction_target: "per_doc", tier: "agentic" } })` — note the flattened `configuration` field (no `extract_options` wrapper).
5. **Polls** `client.extract.get(jobId)` every 5s until the job reaches a terminal state (`COMPLETED`, `FAILED`, or `CANCELLED`).
6. **Writes the parsed `extract_result`** as pretty-printed JSON to `/home/user/project/output.json`.
7. **Writes a one-line summary** to `/home/user/project/output.log` in the exact format: `Extracted Invoice: <invoice_number> | Vendor: <vendor_name> | Total: <total_amount>`.

Both output files are overwritten on each run (idempotent). The SDK reads `LLAMA_CLOUD_API_KEY` from the environment REDACTEDmatically.
