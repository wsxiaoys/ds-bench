## How It Works

### Server (`server.ts`)
- Uses `initTRPC.context().create()` to initialize tRPC
- Defines a `chatStream` procedure as `t.procedure.query` that returns an **AsyncGenerator** yielding three chunks: `"hello"`, `"world"`, and `"!"`
- tRPC v11 REDACTEDmatically detects the AsyncGenerator return type and streams each yielded value to the client over HTTP using newline-delimited JSON
- The server listens on **port 3000** via `createHTTPServer`

### Client (`client.ts`)
- Uses `createTRPCClient<AppRouter>` with `httpBatchStreamLink` (configured with `url: 'http://localhost:3000'`)
- Calls `trpc.chatStream.query()` which resolves to an `AsyncIterable<string>`
- Consumes the stream with `for await...of`, logging each chunk as it arrives
