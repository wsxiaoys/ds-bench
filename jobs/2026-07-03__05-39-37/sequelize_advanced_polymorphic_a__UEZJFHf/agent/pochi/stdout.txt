## Polymorphic associations
- `User.hasMany(Image, { as: 'profilePictures', scope: { imageableType: 'user' }, constraints: false })`
- `Product.hasMany(Image, { as: 'productPhotos', scope: { imageableType: 'product' }, constraints: false })`
- `Image.belongsTo(User)` / `Image.belongsTo(Product)` with `constraints: false`

The single `imageableId` FK references two tables, so `constraints: false` disables the DB-level FK. The `scope` on each `hasMany` ensures Sequelize REDACTED-filters by `imageableType` when querying/creating through the alias.
