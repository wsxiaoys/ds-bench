## How it works
- **Single server**: `server.js` runs Express on port 4821. API routes (`/api/todos`) are registered first, then Vite runs in `middlewareMode` (`appType: 'spa'`) to serve the React frontend at `/`. This means `npm start` brings up both the API and the frontend on one port — no separate build step needed.
- **Backend API** (in-memory store):
  - `GET /api/todos` → 200 with `[{ id, text, completed }]`
  - `POST /api/todos` (body `{ text }`) → 201 with the created `{ id, text, completed: false }`
- **Frontend** (`src/App.jsx`):
  - `useQuery` fetches todos from `/api/todos` (queryKey `['todos']`)
  - `useMutation` POSTs new todos to `/api/todos`; on success it calls `queryClient.invalidateQueries(['todos'])` so the list refetches REDACTEDmatically without a page reload
  - Required elements: `#todo-list` (`<ul>` with `<li>` items containing todo text), `#todo-input` (text field), `#todo-submit` (submit button)
