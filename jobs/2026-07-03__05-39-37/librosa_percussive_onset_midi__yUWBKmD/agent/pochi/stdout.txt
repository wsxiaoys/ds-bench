## Pipeline (all librosa 0.11.0 keyword-only APIs, single `hop_length=512` reused throughout)

1. **Load** — `librosa.load("/home/user/input.wav", sr=22050, mono=True)` → 12.0s, 22050 Hz.
2. **HPSS** — `librosa.effects.hpss(y, hop_length=...)` isolates the percussive waveform; all later analysis uses that percussive-only signal.
3. **Onset detection** — `librosa.onset.onset_strength(y=percussive, sr=, hop_length=)` computes the envelope; `librosa.onset.onset_detect(..., onset_envelope=<same env>, units="frames", pre_max=6, post_max=6, pre_avg=6, post_avg=6, delta=0.07, wait=6)` picks peaks. → **48 onsets** (well above the 5-hit floor).
4. **Beat tracking** — `librosa.beat.beat_track(y=percussive, onset_envelope=<same env>, hop_length=, start_bpm=120, units="frames")` → **tempo ≈ 117.45 BPM**.
5. **16th-note grid** — step = `60 / tempo / 4` ≈ 0.1277 s; grid positions `i*step` for `i` in `[0, floor(duration/step)]` = `[0, 93]`.
6. **Velocity** — sample the onset envelope at each detected frame, rescale by the max so the peak is exactly `1.0`; min stays strictly positive (0.108). Range verified `(0.0, 1.0]`.
7. **Snap** — each raw onset time → `round(t/step)` grid index (clamped into the in-duration range), `time_seconds = grid_index * step`.
8. **Output** — `hits.json` as a top-level object `{"hits": [...], "_metadata": {"estimated_tempo": 117.45}}`, hits sorted chronologically.
