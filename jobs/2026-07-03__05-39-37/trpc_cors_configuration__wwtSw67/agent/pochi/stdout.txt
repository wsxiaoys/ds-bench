## Implementation (`index.ts`)
The server uses `createHTTPServer` from `@trpc/server/adapters/standalone` with the `middleware` option to apply the `cors` package as a connect-style middleware. The CORS is configured with:
- `origin: 'http://localhost:3000'` — allows requests only from the frontend
- `credentials: true` — enables credentialed requests

The router defines a `hello` query that accepts an optional `name` input (validated with Zod) and returns a `{ greeting }` response.

## How to Run
```bash
cd /home/user/project
npx tsx index.ts
# or: npm start
```
Server listens on `http://localhost:4000`.
