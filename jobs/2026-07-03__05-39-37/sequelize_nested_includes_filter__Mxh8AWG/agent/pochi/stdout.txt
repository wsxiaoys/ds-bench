## Endpoints

### POST `/seed`

- Uses `Sequelize.sync({ force: true })` to reset the schema/data, then inserts the nested payload.
- Returns `200 OK` on success.

### GET `/companies/filtered`
- Returns all companies (LEFT OUTER JOIN via `required: false`).
- Includes only departments where `status === 'active'`.
- Within active departments, includes only employees where `role === 'senior'`.
- Companies with no active departments are still returned with an empty `departments` array.
- Active departments with no senior employees are still returned with an empty `employees` array.

## The Key Implementation Detail
The critical part is setting `required: false` on **both** nested includes:

```js
Company.findAll({
  include: [{
    model: Department,
    as: 'departments',
    required: false,          // LEFT JOIN keeps companies w/o active depts
    where: { status: 'active' },
    include: [{
      model: Employee,
      as: 'employees',
      required: false,        // LEFT JOIN keeps active depts w/o senior employees
      where: { role: 'senior' },
    }],
  }],
});
```

By default, Sequelize turns an `include` with a `where` clause into an INNER JOIN, which would drop parent records that have no matching children. Setting `required: false` forces a LEFT OUTER JOIN, preserving the parent records (companies and active departments) even when no matching children exist.
