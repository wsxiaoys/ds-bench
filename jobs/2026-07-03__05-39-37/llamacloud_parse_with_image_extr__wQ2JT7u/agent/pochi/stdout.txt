## What the script does (`/home/user/myproject/parse_pdf.py`)
1. **Instantiates `LlamaCloud()`** — reads `LLAMA_CLOUD_API_KEY` from the environment REDACTEDmatically.
2. **Uploads the PDF** as a parse source file via `client.files.create(file=..., purpose="parse")`.
3. **Submits a Parse job** using the synchronous helper `client.parsing.parse(...)` with:
   - `tier="agentic"` (a non-deprecated parse tier), `version="latest"`
   - `output_options=OutputOptions(images_to_save=["screenshot"])` to request per-page screenshots
   - `expand=["markdown", "images_content_metadata"]` so both the markdown and image content metadata (with presigned download URLs) are returned in one call
4. **Saves the markdown** — concatenates per-page markdown (sorted by page number, separated by blank lines) to `output/markdown.md`.
5. **Downloads & saves screenshots** — filters images by `category == "screenshot"`, sorts by index, fetches each via its presigned URL, converts from JPEG to genuine PNG, and writes `output/images/page_<N>.png` (1-based).
6. **Writes the log** to `output/output.log` with the three required lines.
