- `rebind_action(action: StringName, new_event: InputEvent) -> void` — erases existing keyboard/joypad events from the action, adds `new_event`, emits the signal.
- `get_action_event(action: StringName) -> InputEvent` — returns the first currently bound event (or `null`).
- `save_to_file(path: String = "user://input_map.cfg") -> void` — `ConfigFile` serialization; stores `InputEventKey` by `keycode` (+ `physical_keycode`/`unicode`) and `InputEventJoypadButton` by `button_index`.
- `load_from_file(path: String = "user://input_map.cfg") -> bool` — restores bindings; returns `false` when the file is absent, `true` otherwise.
- `reset_to_defaults() -> void` — restores the bindings snapshot captured in `_ready()`.
- `signal action_rebound(action: StringName, event: InputEvent)` emitted by `rebind_action`.

**`scenes/RemapButton.gd`** (`@tool class_name RemapButton extends Button`)
- `@export var action_name: StringName`.
- Displays current binding via `InputEvent.as_text()` and refreshes in-editor via `_process`.
- On press enters a listening state; `_unhandled_input` captures the next `InputEventKey`/`InputEventJoypadButton` press (ignoring echoes/releases) and calls `InputRemapper.rebind_action(action_name, event)`.

**`scenes/RemapButton.tscn`** — Button root with the script attached and `action_name = &"move_up"`.
