## What the script does

It builds a single `alt.Chart` (mark `bar`, no faceting/concatenation) over the URL string `data.population.url` from `altair.datasets`, so encoding shorthands (`:Q`, `:O`, `:N`) are required.

Key spec elements confirmed in `pyramid_spec.json`:

- **Signed x value computed in-spec**: `transform_calculate` with `datum.sex === 1 ? -datum.people : datum.people` → field `people_signed` (males negative/left, females positive/right). Not pre-computed in pandas.
- **Year dropdown**: one `alt.param(name="year", value=1980)` bound to `alt.binding_select(options=[1850…2000])` (distinct census years), default `1980`. `transform_filter("datum.year == year")` filters to the selected year.
- **Y axis**: `alt.Y("age:O", sort="descending")` → oldest age at top, youngest at bottom.
- **X axis labels**: `alt.Axis(format="s", labelExpr="abs(datum.value)")` → absolute-value SI labels on both sides.
- **Color/legend**: `alt.Color("sex:N")` with `scale(domain=[1,2], range=["steelblue","salmon"])` and `legend(labelExpr="datum.value === 1 ? 'Male' : 'Female'")` → legend reads "Male"/"Female", not 1/2.
