## What it does

The script is a CLI tool that classifies a single PDF into one of three categories (invoice, receipt, contract) using the LlamaCloud Classifier (beta), then prints a single line of JSON to stdout.

## How it works

1. **Argument parsing** — Uses `argparse` with a single positional `file` argument, invokable as `python3 classify.py <file>`.
2. **Path resolution** — Resolves the input to an absolute path via `pathlib.Path(...).resolve()` (this is the `file` value echoed in the output) and verifies the file exists.
3. **API key** — Reads `LLAMA_CLOUD_API_KEY` from the environment; errors out (exit 1) if it's missing/empty.
4. **Client** — Instantiates `from llama_cloud import LlamaCloud` (modern `llama-cloud` SDK v2.x, not the legacy `llama-cloud-services` wrapper), passing the key explicitly.
5. **Upload** — `client.files.create(file=<path>, purpose="classify")`, capturing the returned `id`.
6. **Classify** — `client.classifier.classify(file_ids=[file_id], rules=RULES, mode="FAST")`. This convenience method uploads/runs/polls/returns in one call.
7. **Rules** — Exactly three rules in the required order:
   - `invoice` — invoice number, invoice date, bill-to section, line items with totals
   - `receipt` — short POS purchase receipts with merchant, items, total, often single page
   - `contract` — multi-section legal agreement with parties, terms, signature lines
8. **Result extraction** — Takes the single item from `response.items` and reads `result.type`, `result.confidence` (and `result.reasoning` is available).
9. **Output** — Prints one JSON line: `{"type": ..., "confidence": ..., "file": <absolute path>}`.
10. **Exit codes** — `0` on success; non-zero (`1`) on any error (missing file, missing key, upload failure, classifier failure, empty/invalid result), with the error message written to stderr.
