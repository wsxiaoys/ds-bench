The script uses the Daytona Python SDK (v0.193.0) to perform the complete flow:

1. **Reads run-id** from `/logs/artifacts/run-id` → `zr7lrw1raz`
2. **Creates a local input file** at `/home/user/myproject/input.txt` with content `Hello Daytona zr7lrw1raz`
3. **Provisions a sandbox** named `fs-py-zr7lrw1raz` via `Daytona().create(CreateSandboxFromSnapshotParams(name=...))`
4. **Uploads** the local file into the sandbox via `sandbox.fs.upload_file(content, remote_path)`
5. **Transforms** the file in-sandbox with `sandbox.process.exec("tr '[:lower:]' '[:upper:]' < input.txt > output.txt")`, checking the exit code
6. **Downloads** the transformed file via `sandbox.fs.download_file(remote_path)` and writes the bytes to `/home/user/myproject/output.txt`
7. **Writes the confirmation** `Upload+Download OK` to `/home/user/myproject/output.log`
8. **Deletes the sandbox** in a `finally` block so it is always cleaned up, even on failure
