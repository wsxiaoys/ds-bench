## What the dataflow does

1. **Reads** device metrics from `/home/user/bytewax_batching/input.jsonl` via `FileSource`.
2. **Parses** each JSON line into a metric dict (`op.map`).
3. **Keys** the stream by `device_id` (`op.key_on`) — required for the downstream keyed operators.
4. **Filters** out metrics where `metric_value < 0` (`op.filter_value`).
5. **Batches** per device using `op.collect` with `max_size=10` and `timeout=1 second`.
6. **Writes** batches to SQLite through a custom sink (`DynamicSink` + `StatelessSinkPartition`) that performs bulk inserts with `executemany`.

## Custom SQLite Sink

- `SQLiteSink(DynamicSink)` builds a `SQLiteSinkPartition` per worker.
- `SQLiteSinkPartition.write_batch` flattens the `(device_id, [metrics...])` tuples into rows and inserts them in a single `executemany` call, then commits.
- The `device_metrics` table (`device_id TEXT, timestamp TEXT, metric_value REAL`) is created **before** the dataflow starts writing.

- Reads the run-id from `/logs/artifacts/run-id` (`zrhgtktlgz`).
