**How it works:**

The script uses `prisma.$transaction(async (tx) => { ... })` so the balance check and both updates run atomically inside a single transaction. If any step throws, Prisma rolls the whole transaction back REDACTEDmatically — no partial debits/credits can be committed.

Steps inside the transaction:
1. `tx.account.findUnique({ where: { owner: 'alice' } })` — fetch the sender.
2. Guard: if `sender.balance < 50`, throw `Insufficient funds` (which aborts the transaction).
3. `tx.account.update({ where: { owner: 'alice' }, data: { balance: { decrement: 50 } } })` — debit the sender.
4. `tx.account.update({ where: { owner: 'bob' }, data: { balance: { increment: 50 } } })` — credit the receiver.

After the transaction commits, the script re-queries both accounts and writes the final balances to `transfer_result.json`.
