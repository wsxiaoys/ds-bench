## Changes Made

### 1. Custom `errorFormatter` added to `initTRPC.create()`

```typescript
export const t = initTRPC.create({
  errorFormatter({ shape, error }) {
    return {
      ...shape,
      data: {
        ...shape.data,
        zodError:
          error.code === 'BAD_REQUEST' && error.cause instanceof ZodError
            ? error.cause.flatten()
            : null,
      },
    };
  },
});
```

This checks if the error is a `BAD_REQUEST` and the cause is a `ZodError`. If so, it appends `zodError: error.cause.flatten()` to the `data` object. Otherwise, `zodError` is `null`.

### 2. Fixed Express middleware argument ordering (pre-existing bug)

The original `app.use(express.json(), '/trpc', ...)` had the arguments in the wrong order for Express v5, which prevented the server from compiling/starting. Fixed to `app.use('/trpc', express.json(), ...)` (path first).
