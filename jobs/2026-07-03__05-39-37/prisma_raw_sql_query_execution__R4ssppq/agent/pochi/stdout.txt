## What the script does
1. **Imports** `PrismaClient` and the `Prisma` namespace from `@prisma/client`.
2. **Counts users** with a raw SQL tagged template literal:
   ```js
   const countResult = await prisma.$queryRaw`SELECT COUNT(*) as cnt FROM User`;
   ```
   → returns `[{ cnt: 3n }]` (BigInt, since `$queryRaw` returns BigInt for integer-like columns on SQLite).
3. **Updates all names to uppercase** with raw SQL execution:
   ```js
   await prisma.$executeRaw`UPDATE User SET name = UPPER(name)`;
   ```
4. **Queries all users** after the update using `prisma.user.findMany()`.
5. **Writes results** to `/home/user/myproject/rawsql_result.json`, using a JSON replacer to convert the BigInt count value to a plain number (JSON.stringify can't serialize BigInt by default).

## Result (`rawsql_result.json`)
```json
{
  "countResult": [
    { "cnt": 3 }
  ],
  "users": [
    { "id": 1, "email": "alice@example.com", "name": "ALICE" },
    { "id": 2, "email": "bob@example.com", "name": "BOB" },
    { "id": 3, "email": "carol@example.com", "name": "CAROL" }
  ]
}
```

Note: The `$executeRaw` UPDATE is a real, persistent DB change, so the seed users' names are now uppercase (`ALICE`, `BOB`, `CAROL`) in the SQLite `dev.db`. Re-running the script is idempotent since `UPPER()` of already-uppercase names leaves them unchanged.
