## What changed
In tRPC v11, the `transformer` option was removed from the root `createTRPCClient` config and must instead be specified **per-link**. The `httpBatchLink` options type includes `TransformerOptions`, so the transformer lives directly inside the link configuration object.

**Before (v10-style — broken in v11):**
```ts
export const trpc = createTRPCClient<AppRouter>({
  transformer: superjson,
  links: [
    httpBatchLink({
      url: 'http://localhost:3000',
    }),
  ],
});
```

**After (v11-correct):**
```ts
export const trpc = createTRPCClient<AppRouter>({
  links: [
    httpBatchLink({
      url: 'http://localhost:3000',
      transformer: superjson,
    }),
  ],
});
```
