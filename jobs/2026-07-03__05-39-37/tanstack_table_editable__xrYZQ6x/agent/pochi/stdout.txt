## What was built

**Tech stack:** Vite + React 19, `@tanstack/react-table`, `@tanstack/react-form`

**Key files:**
- `src/App.jsx` — Main component with the data grid and inline editing logic

## Features implemented

1. **Data grid via TanStack Table** (`useReactTable` + `getCoreRowModel`) with columns: ID, Name, Email, Role, Actions. Starts with 4 user records.

2. **Inline editing** — Clicking an **Edit** button on a row stores the row ID in state and renders an `EditRow` component in place of that row's display cells.

3. **TanStack Form for edit state + validation** (`useForm`):
   - **Name** — required (non-empty) validator on both `onChange` and `onBlur`
   - **Email** — required + regex format validation (`/^[^\s@]+@[^\s@]+\.[^\s@]+$/`)
   - **Role** — select dropdown (Admin / Editor / Viewer)
   - Validation errors render inline beneath each field and prevent submission.

4. **Save / Cancel buttons** appear in edit mode:
   - **Save** — calls `form.handleSubmit()`, which only succeeds when all fields are valid; updates the table data and exits edit mode.
   - **Cancel** — reverts changes (form is discarded) and exits edit mode immediately.

5. **Dev server runs on port 5732** via `npm run dev` (verified with both a production build and a live dev server check).
