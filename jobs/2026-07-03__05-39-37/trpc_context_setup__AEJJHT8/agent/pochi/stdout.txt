## Files Created

### 1. `src/trpc/init.ts` — tRPC Initialization
- Defines the `Context` interface with a `userId` field
- Initializes tRPC with `initTRPC.context<Context>().create()`
- Exports `router` and `procedure` builders for use in the router

### 2. `src/trpc/router.ts` — Application Router
- Imports `router` and `procedure` from `init.ts`
- Defines a single `getUser` query procedure that returns `{ userId: ctx.userId }`
- Exports `appRouter` (the instance) and `AppRouter` (the type)

### 3. `src/app/api/trpc/[trpc]/route.ts` — Next.js App Router Handler
- Uses `fetchRequestHandler` from `@trpc/server/adapters/fetch`
- Implements `createContext` which reads the `x-user-id` header from the standard Web `Request` object, defaulting to `'anonymous'` when the header is missing
- Exports the handler as both `GET` and `POST` (required by Next.js App Router)

## How It Works

`fetchRequestHandler` receives the raw `Request` object from Next.js and passes it to the `createContext` function. The context extracts the `x-user-id` header and makes it available to all tRPC procedures via `ctx.userId`.
