## What the script does (in order)
1. **Upload v1** — Reads the run id from `/logs/artifacts/run-id` (`zrtxd6o9tv`), builds `harbor-awscli-${run_id}`, normalizes it (lowercase + replace invalid chars like `_` with `-` → `harbor-awscli-zrtxd6o9tv`), and uploads `v1.txt` with body `version=1` (UTF-8, no trailing newline) via the AWS S3 SDK pointed at `REDACTED` (region `REDACTED`).
2. **Checkpoint** — Calls `checkpoint(bucketName, { name: "before-mutation" })` from `@tigrisdata/agent-kit` and saves the returned `snapshotId`.
3. **Mutate** — Overwrites the same key `v1.txt` with body `version=2`.
4. **Restore** — Calls `restore(bucketName, snapshotId, { forkName: "rollback-recovery" })`, reads the real fork name from `restored.bucket`, and writes it to `/home/user/chained-ckpt/recovery.json` as `{"recoveryBucket": "<name>"}`.
5. **Tear down** — Deletes only the recovery fork bucket via `removeBucket(recoveryBucket, { force: true })` from `@tigrisdata/storage`. The source bucket, its `v1.txt` object, and the snapshot are left intact.

Every Agent Kit / storage call checks `result.error` (discriminated unions, never throws), and the process exits `0` on success.
