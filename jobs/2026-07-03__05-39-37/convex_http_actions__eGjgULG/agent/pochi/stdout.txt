## What was built

**`convex/schema.ts`** — Defines the `webhooks` table with `payload` (string) and `runId` (string) fields.

**`convex/webhooks.ts`** — Contains:
- `insertWebhook` — an **internal mutation** that inserts a record into the `webhooks` table (called from the HTTP action via `ctx.runMutation`, since HTTP actions can't write to the DB directly).
- `get_webhook` — a **public query** accepting a `runId` string argument and returning all webhook records matching that `runId` (filtered so concurrent test runs don't interfere).

**`convex/http.ts`** — Exposes `POST /webhook` via `httpRouter` + `httpAction`. It parses the JSON body, validates that `payload` and `runId` are present strings, then calls the internal mutation to store the record. Returns `{"success":true}` (200) on success, and proper 400 errors for invalid JSON or missing/invalid fields.
