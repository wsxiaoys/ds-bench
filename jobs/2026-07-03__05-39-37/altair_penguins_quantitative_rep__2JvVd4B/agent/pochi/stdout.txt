## What the script does

`build_chart.py` builds a 2×2 SPLOM of the Palmer Penguins dataset using Vega-Altair's `repeat` operator and saves it as a self-contained HTML page:

- **Data source:** `data.penguins.url` from `vega_datasets` (URL-based, so field types are declared explicitly as `quantitative`).
- **Base chart:** `alt.Chart(data.penguins.url).mark_point()` with `width=180`, `height=180`.
- **Encodings:**
  - `x = alt.X(alt.repeat("column"), type="quantitative", scale=alt.Scale(zero=False))`
  - `y = alt.Y(alt.repeat("row"), type="quantitative", scale=alt.Scale(zero=False))`
  - `color = alt.Color("Species:N")` (shared legend across all panels)
- **Repeat grid:** `row=["Body Mass (g)", "Flipper Length (mm)"]`, `column=["Beak Length (mm)", "Beak Depth (mm)"]`.
- **Output:** `chart.save("/home/user/myproject/chart.html")`, producing an HTML page that loads Vega / Vega-Lite / vega-embed from the jsDelivr CDN.
