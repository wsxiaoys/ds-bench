## What it does

**`build_index()`** (called first by the verifier, then cached):
- Reads the 90-row corpus from `/home/user/myproject/corpus.json`.
- Embeds every sentence via the official `cohere` SDK (`ClientV2`) with `model="embed-multilingual-v3.0"`, `input_type="search_document"`, and `embedding_types=["float"]`, batched at 96 texts/request (Cohere's limit). It normalizes the response defensively across both the V2 `response.embeddings.float_` form and the legacy list-of-lists form.
- Persists all 90 rows into a run-scoped LanceDB table `multilingual_<run-id>` (run-id read from `/logs/artifacts/run-id` → `multilingual_zrz3f9dr4j`) under `lancedb_data/`, using an explicit PyArrow schema: `concept_id` (int32), `language` (string), `text` (string), `vector` (`fixed_size_list<float32>[1024]`).

**`cross_lingual_search(query: str, k: int = 3) -> list[dict]`**:
- Embeds the query with `input_type="search_query"`.
- Runs a cosine search against the table across **all three languages** (no language filter), sorted by ascending distance.
- Returns a list of dicts each with exactly `concept_id`, `language`, and `text`.
