## How it works

The `checkout(productId, quantity)` function uses `prisma.$transaction(async (tx) => { ... })` to guarantee atomicity. Inside the transaction:

1. **Stock check** — Reads the product via `tx.product.findUnique` and throws `Error('Insufficient stock')` if `product.stock < quantity`.
2. **Decrement stock** — `tx.product.update({ where: { id: productId }, data: { stock: { decrement: quantity } } })`.
3. **Create order** — `tx.order.create({ data: { productId, quantity } })`.

Because both writes run inside a single interactive transaction, if the stock check throws, neither the decrement nor the order creation is committed — the whole transaction rolls back.
