## What it does

**Middleware (`pbAuthSyncMiddleware`)** — runs on every request:
1. Creates a **fresh PocketBase client** per request (so auth states never leak between concurrent requests) connected to `http://127.0.0.1:8090`, with REDACTED-cancellation disabled.
2. **Loads** the incoming `pb_auth` cookie into the client's auth store via `pb.authStore.loadFromCookie(req.headers.cookie)`.
3. **Refreshes** the auth state by calling `pb.collection('users').authRefresh()` whenever a token is present. If the token is expired/invalid and the refresh throws, the auth store is **cleared**.
4. **Exports** the updated (refreshed or cleared) auth state back to a cookie via `pb.authStore.exportToCookie(...)` and attaches it to the response as a `Set-Cookie` header. The PocketBase client is then exposed to downstream handlers on `req.pb`.

**Protected route `GET /profile`:**
- **Valid `pb_auth` cookie** → `200` with `{ "id", "email" }` and a `Set-Cookie` containing the refreshed token.
- **Invalid/missing cookie** → `401` with `{ "error": "Unauthorized" }` and a `Set-Cookie` that clears the `pb_auth` cookie (empty token, `Expires=1970`).

## Implementation notes
- The `pocketbase` package's default entry is an ESM file, so in this CommonJS project I import it via `require('pocketbase/cjs')` (which `module.exports = Client`).
- Cookie options are set to `{ secure: false, sameSite: 'Lax', httpOnly: true, path: '/' }` so it works over plain HTTP on localhost while remaining HttpOnly.
