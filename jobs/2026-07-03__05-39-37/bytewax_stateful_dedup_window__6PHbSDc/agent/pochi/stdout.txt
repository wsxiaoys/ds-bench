    return e

    out = dict(e)
    out['timestamp'] = out['timestamp'].strftime('%Y-%m-%dT%H:%M:%SZ')
    return json.dumps(out, separators=(',', ':'))

class DedupLogic(StatefulLogic):
    def __init__(self, resume_state=None):
        self.state = resume_state if resume_state is not None else {}

## What it does

The dataflow reads JSON events from `input.jsonl`, groups them by `user_id`, and uses Bytewax's `stateful` operator with a custom `StatefulLogic` subclass to deduplicate events over a sliding 10-second window.

## Pipeline (6 steps)

1. **`op.input` + `FileSource`** — Reads raw JSON lines from `input.jsonl` with `batch_size=1` to preserve input ordering (prevents the stateful operator from reordering items across keys within a batch).
2. **`op.map("parse")`** — Parses each JSON line into a dict and converts the ISO 8601 timestamp string into a `datetime` object.
3. **`op.key_on("key_on_user")`** — Keys the stream by `user_id` (required for stateful operators).
4. **`op.stateful("dedup")`** — Applies `DedupLogic`, a `StatefulLogic` subclass that performs per-key deduplication.
5. **`op.map_value("serialize")`** — Serializes surviving events back to JSON strings.
6. **`op.output` + `FileSink`** — Writes JSON strings (one per line) to `output.jsonl`.

## Deduplication logic (`DedupLogic`)

- **State**: A `dict` mapping `event_id → datetime` (timestamp of last emitted occurrence).
- **On each item**:
  1. **Dynamic cleanup**: Removes any `event_id` whose stored timestamp is strictly older than 10 seconds from the current event's timestamp (`current_ts - stored_ts > 10s`).
  2. **Dedup check**: If the `event_id` is in state and `current_ts <= prev_ts + 10s` (inclusive of exactly 10 seconds), the event is **dropped** (emits nothing).
  3. Otherwise, the event is **emitted** and the state is updated with the current timestamp, restarting the 10-second window for that `event_id`.
- **`snapshot`**: Returns a copy of the state dict for recovery.
