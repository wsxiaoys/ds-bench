## How it works

**Authentication state** — `src/auth.tsx` provides a React Context with `isAuthenticated` (defaults to `false`), `login()`, and `logout()`. The `AuthProvider` wraps the `RouterProvider`.

**Router context bridge** — The router is created with a `context.auth` slot (`undefined!` placeholder). The `App` component (rendered inside `AuthProvider`) calls `useAuth()` and passes the live auth value to `RouterProvider` via its `context` prop, so route guards have access to current auth state.

**Route protection** — The `/dashboard` route uses `beforeLoad`:
```ts
beforeLoad: ({ context }) => {
  if (!context.auth.isAuthenticated) {
    throw redirect({ to: '/login' })
  }
}
```

## Routes
- **`/`** — Public home page with a link "Go to Dashboard" → `/dashboard`.
- **`/login`** — Contains a "Login" button that calls `login()` (sets `isAuthenticated = true`) and redirects to `/dashboard`.
- **`/dashboard`** — Protected. Unauthenticated users are redirected to `/login`. When authenticated, displays "Welcome to Dashboard" and a "Logout" button that calls `logout()` and redirects to `/login`.
