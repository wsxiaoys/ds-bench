Created `/home/user/project/flow.py` with the following implementation:

```python
from prefect import flow, task


def cache_key(context, parameters):
    return "fetch-" + parameters["url"]


@task(cache_key_fn=cache_key)
def fetch_data(url: str):
    return "Data from " + url


@flow
def process_data():
    result1 = fetch_data("http://example.com")
    result2 = fetch_data("http://example.com")
    print(result1)
    print(result2)


if __name__ == "__main__":
    process_data()
```

The script meets all requirements:
- **`fetch_data(url: str)` task** — returns `"Data from " + url`, decorated with `@task` (Prefect 3.0 syntax).
- **`cache_key_fn`** — the `cache_key` function accepts `context` and `parameters`, returning `"fetch-" + parameters["url"]`, so both calls with the same URL share a cache key.
- **`process_data()` flow** — calls `fetch_data("http://example.com")` twice and prints both results.
- **Runs directly** — guarded by `if __name__ == "__main__"`.
