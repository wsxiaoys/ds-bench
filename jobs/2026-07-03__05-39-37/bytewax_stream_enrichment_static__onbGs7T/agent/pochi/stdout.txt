## What it does

1. **Loads static metadata** — `products.json` is read once at import time into a global `PRODUCTS` dict (`product_id → {category, price}`).
2. **Ingests the transaction stream** — reads `transactions.jsonl` line-by-line via `FileSource`.
3. **Parses & enriches** — each JSON line is parsed, then enriched with `category` and `price`. Transactions whose `product_id` is absent from the static dataset are dropped (using `filter_map`, returning `None`).
4. **Event-time windowing** — transactions are keyed by `category`, then aggregated with `fold_window` using:
   - `EventClock` that extracts the timezone-aware `timestamp` from each event (parsed from the ISO-8601 `Z` format).
   - `TumblingWindower(length=1 minute, align_to=Unix epoch)`. Aligning to the epoch (itself on an hour boundary) ensures the 1-minute windows also align to the start of every hour.
5. **Formats & outputs** — each windowed result `(category, (window_id, revenue))` is mapped to a JSON string. The `window_start` is recovered from the window id via `align_to + length * window_id`, then emitted to `StdOutSink`.
