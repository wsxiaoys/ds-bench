**`/home/user/myproject/main.go`** — registered `OnRecordCreateRequest("articles")` and `OnRecordUpdateRequest("articles")` hooks (both bound to a single shared handler via `BindFunc`):

```go
registerArticleHooks := func(e *core.RecordRequestEvent) error {
    content := e.Record.GetString("content")
    wordCount, readingTime := computeArticleStats(content)

    e.Record.Set("word_count", wordCount)
    e.Record.Set("reading_time_minutes", readingTime)

    return e.Next() // continue the chain so the record is persisted
}

app.OnRecordCreateRequest("articles").BindFunc(registerArticleHooks)
app.OnRecordUpdateRequest("articles").BindFunc(registerArticleHooks)
```

The `computeArticleStats` helper uses `strings.Fields` (whitespace-separated word count) and `math.Ceil(wordCount / 200.0)`, with a special-case guard so 0 words → 0 minutes (since `ceil(0/200)` would be 0 anyway, but the guard makes the intent explicit). The computed values are written with `e.Record.Set`, which overwrites any client-supplied `word_count` / `reading_time_minutes`, so clients cannot bypass the calculation. `e.Next()` is returned so the middleware chain continues and the record is saved.
