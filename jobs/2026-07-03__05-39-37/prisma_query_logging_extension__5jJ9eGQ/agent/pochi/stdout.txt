## What the script does

1. **Creates an extended Prisma client** using the `$extends` API with a `query` component. The `$allModels.$allOperations` interceptor wraps every database operation.
2. **Runs 3 queries** against the `User` model:
   - `xprisma.user.findMany()`
   - `xprisma.user.count()`
   - `xprisma.user.findFirst()`
3. **Logs each query** to `/home/user/myproject/query.log` as a JSON line containing `{ model, operation, args }` (the log is cleared at the start so the count reflects only the current run).
4. **Counts the logged lines** and writes the result to `/home/user/myproject/logging_result.json`.
