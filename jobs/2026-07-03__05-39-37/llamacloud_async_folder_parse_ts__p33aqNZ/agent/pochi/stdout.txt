## What it does
- Discovers every `.pdf` under `./inputs/` (attention.pdf, bert.pdf, gpt3.pdf).
- Uploads each via `client.files.create({ file: fs.createReadStream(...), purpose: "parse", external_file_id })`, tagging uploads with `<run-id>-<basename>` read from `/logs/artifacts/run-id` (e.g. `zrvch7ao9x-attention`) so concurrent runs don't collide.
- Parses each upload via `client.parsing.parse({ file_id, tier: "cost_effective", version: "latest", expand: ["markdown"] })`.
- Caps concurrency to **2** in-flight jobs using `p-limit` (verified in the run log: bert+attention upload together, then gpt3 starts only after one finishes).
- Concatenates every page's `markdown` field joined by `\n\n---\n\n` and writes it to `./outputs/<basename>.md`.
- Writes one summary line per PDF to `./output.log` in the format `Parsed: <basename>.pdf | pages: <N>`, where N is `result.markdown.pages.length`.
