## What the dashboard does

Drag a 2D brush over the scatter plot (View A) and the bar chart (View B) and histogram (View C) below update to show only the rows whose scatter point falls inside the brush.

## Implementation details

**Data source**: `data.movies.url` (URL-based; all encoding types declared explicitly, e.g. `IMDB_Rating:Q`, `Major_Genre:N`).

**Pre-filtering nulls**: Every view applies `transform_filter(alt.datum.IMDB_Rating != None)`. The scatter additionally filters `alt.datum.Rotten_Tomatoes_Rating != None`. These compile to `datum.IMDB_Rating !== null` / `datum.Rotten_Tomatoes_Rating !== null` in the Vega-Lite spec.

**Brush**: A single `alt.selection_interval(encodings=["x","y"], name="brush")` is created once and reused:
- Attached to the scatter via `add_params(brush)`.
- Referenced by `alt.condition(brush, "Major_Genre:N", alt.value("lightgray"))` for scatter color (inside → colored by genre, outside → flat lightgray).
- Referenced by `transform_filter(brush)` on both the bar chart and histogram.

**Views**:
1. **View A (scatter, brush host)** — `mark_point` of `IMDB_Rating` (x) vs `Rotten_Tomatoes_Rating` (y).
2. **View B (genre bar)** — `mark_bar` of count per `Major_Genre`, brush-filtered, restricted to the top 8 genres via `transform_aggregate` → `transform_window(rank)` → `transform_filter(datum.rank <= 8)`.
3. **View C (rating histogram)** — `mark_bar` histogram of `IMDB_Rating` with `bin(maxbins=20)` and `count()`, brush-filtered.

**Layout**: `scatter & (bar | hist)` → `vconcat[scatter, hconcat[bar, hist]]` (scatter on top, bar and histogram side-by-side underneath).

**Export**: `dashboard.save(OUTPUT, inline=True)` bundles the Vega/Vega-Lite/Vega-Embed JavaScript directly into the HTML so the file is fully self-contained (no external CDN script requests). The embedded spec is rendered by `vegaEmbed`, making the brush interactive when opened in a browser.
