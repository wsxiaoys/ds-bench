## How it works
The single Altair chart is a vertical concatenation (`&`) of two equal-width panels sharing the same URL data source (`data.sp500.url` — no pandas pre-processing):

1. **Upper detail chart** (`height=400`): a filled `area` of `price` vs `date` whose x-scale `domain` is bound directly to the brush parameter (`alt.X("date:T").scale(domain=brush)`), so it zooms to the brushed range.

2. **Lower context chart** (`height=60`): the same filled `area` acting as a navigator, hosting the interval brush created with `alt.selection_interval(encodings=["x"])` and registered via `add_params(brush)`.

3. **Running-maximum rule**: layered on top of the detail chart. It narrows the dataset to the brushed window with `transform_filter(brush)`, then computes the maximum price entirely in-spec with `transform_aggregate(max_price="max(price)")`, and draws a horizontal `rule` mark (`y="max_price:Q"`) spanning the full width.

Running `python3 build_chart.py` produced `chart.html`. Inspecting the embedded Vega-Lite spec confirmed:

- the rule layer's `transform` chain is `[filter, aggregate]` with `max_price`
- the spec is a `vconcat` of the detail (layered area+rule) and context (area) panels
