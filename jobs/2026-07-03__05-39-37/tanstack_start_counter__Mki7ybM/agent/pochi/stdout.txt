## Key Files

**`package.json`** — Dependencies include `@tanstack/react-start`, `@tanstack/react-router`, `react`, `react-dom`, and Vite 8 with `@vitejs/plugin-react`. The `dev` script runs `vite dev`.

**`vite.config.ts`** — Configured with the `tanstackStart()` plugin and `server.port: 8234`.

**`src/routes/index.tsx`** — Contains the counter logic:
- An in-memory `count` variable on the server
- A `getCount` server function (GET) that returns the current count
- An `incrementCount` server function (POST) that increments the counter and returns the new value
- The route loader fetches the initial count via `getCount()`
- The page displays `Count: {state}` and an `Increment` button
- Clicking the button calls `incrementCount()`, then `router.invalidate()` to refresh the loader data and update the UI
