## What was done

**1. Prisma schema** (`prisma/schema.prisma`) — defined three models with full relations:
- `User`: id, email (unique), name + relations to posts & comments
- `Post`: id, title, content (optional), published (@default(false)), authorId (FK), createdAt (@default(now())) + comments relation
- `Comment`: id, body, postId (FK), authorId (FK)

**2. Migration** — ran `prisma migrate dev --name init`, creating `prisma/migrations/20260703054209_init/migration.sql` and the SQLite `dev.db`.

**3. Prisma Client** — generated the client. Note: this project uses **Prisma 7.8**, which removed the legacy Rust engine and requires a **driver adapter** for the query-compiler engine. Installed `@prisma/adapter-better-sqlite3` + `better-sqlite3`, and the client is instantiated as:
```js
const adapter = new PrismaBetterSqlite3({ url: dbPath });
const prisma = new PrismaClient({ adapter });
```

**4. Express server** (`server.js`, port 3000) with all endpoints:
| Endpoint | Behavior |
|---|---|
| `POST /users` | create user (email, name) |
| `GET /users/:id/posts` | published posts by user, each with `_count.comments` |
| `POST /posts` | create post `{ title, content, authorId }` |
| `PATCH /posts/:id/publish` | set `published: true` |
| `POST /posts/:id/comments` | add comment `{ body, authorId }` |
| `GET /posts/:id` | post with author + comments (incl. comment authors) |
