## How the chart is constructed (`build_chart.py`)

1. **Data source** — `source = data.barley.url` (from `altair.datasets`). The chart is built directly from this URL so the exported spec retains an explicit `barley` dataset reference (`data.url → .../barley.json`) instead of inlining rows.
2. **Grouped bars** — `mark_bar` with:
   - `x = site:N`, sorted by aggregated yield descending via the method-based syntax `alt.X("site:N").sort(field="yield", op="mean", order="descending")`.
   - `xOffset = variety:N` to group varieties within each site.
   - `y = mean(yield):Q`.
   - `color = variety:N` with `scale=alt.Scale(scheme="tableau10")`.
3. **Per-site mean overlay** — a separate `mark_tick` layer (black, horizontal, thickness 2.5) that derives the per-site mean **inside the spec** using `transform_aggregate(site_mean="mean(yield)", groupby=["site", "year"])`, encoding `x = site:N` (same descending sort) and `y = site_mean:Q`. Grouping includes `year` because the layer is faceted on year, so each facet keeps a single year.
4. **Composition** — `alt.layer(bars, site_mean_ticks)` (the `+` equivalent), then `.facet(row=alt.Row("year:O", title="Year"))`, producing one panel per year (1931 and 1932 → 2 facets).
5. **Title** — `alt.Title(text="Barley Yield by Site and Variety", subtitle="Grouped mean yield per (site, variety), faceted by year, with the per-site average overlaid as a tick", anchor="start")`, providing both a main line and a subtitle.
6. **Export** — `chart.save(...)` writes a standalone HTML page with the spec inlined and Vega/Vega-Lite/Vega-Embed loaded from CDN.
