## What the script does

1. **Connects to a single E2B Sandbox** using `with Sandbox.create() as sandbox:` — the context manager guarantees the sandbox is closed at the end, so it's never left running indefinitely.
2. **Creates two isolated code execution contexts** via `sandbox.create_code_context(cwd="/home/user", language="python")` → `ctx1` and `ctx2`. Each context has its own independent global namespace, so variables don't clash.
3. **Sets `magic_number = 42` in `ctx1`** using `sandbox.run_code("magic_number = 42", context=ctx1)`.
4. **Sets `magic_number = 99` in `ctx2`** using `sandbox.run_code("magic_number = 99", context=ctx2)`.
5. **In `ctx1`**, reads `magic_number` and writes it to `/home/user/out1.txt` inside the sandbox.
6. **In `ctx2`**, reads `magic_number` and writes it to `/home/user/out2.txt` inside the sandbox.
7. **Downloads both files** to the local workspace using `sandbox.files.read(path, format="text")` and writes them to `/home/user/host_out1.txt` and `/home/user/host_out2.txt`.
8. **Closes the sandbox** REDACTEDmatically when the `with` block exits.
