The script uses Prisma's `aggregate` and `groupBy` APIs to compute order statistics:

**aggregate.js**:
- Imports `PrismaClient` from `@prisma/client`
- Runs `prisma.order.aggregate({ _count: true, _sum: { amount: true }, _avg: { amount: true } })` for overall totals
- Runs `prisma.order.groupBy({ by: ['status'], _count: true, _sum: { amount: true } })` for per-status breakdown
- Shapes the results into `{ totals: { count, sum, avg }, byStatus: [{ status, count, sum }] }` and writes them to `aggregate_result.json`
- Disconnects the client in a `finally` block
