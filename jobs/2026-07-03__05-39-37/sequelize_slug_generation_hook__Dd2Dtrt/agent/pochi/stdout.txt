## Key Implementation Details

**Slug generation** (`models/Article.js`): A `generateSlug()` helper lowercases the title and replaces spaces with hyphens.

**Hooks** — the critical detail here is hook ordering:
- I used `beforeValidate` (not `beforeCreate`) for individual inserts. Sequelize runs validation *before* `beforeCreate`, so a `beforeCreate` hook setting `slug` would fail the `allowNull: false` validation. `beforeValidate` populates the slug before validation runs.
- I used `beforeBulkCreate` for bulk inserts. Individual hooks like `beforeValidate`/`beforeCreate` do **not** fire during `bulkCreate` by default, so a separate bulk hook handles the array of instances.

**Endpoints** (`index.js`):
- `POST /articles` → creates one article, returns `201` with `{ id, title, slug }`
- `POST /articles/bulk` → accepts an array, creates all via `bulkCreate`, returns `201` with an array of `{ id, title, slug }`

The database is synced with `force: true` on startup so each server start begins fresh.
