## What was built

A Vite + React + TypeScript app with TanStack Query managing paginated feed state.

### Key files
- `src/api/feed.ts` — Mock API that serves paginated feed data. It generates 60 items total, returns 10 per page, and each page includes a `nextCursor` (set to `null` when the end is reached). Includes simulated network latency.
- `src/components/Feed.tsx` — The feed component using `useInfiniteQuery` from `@tanstack/react-query`. It flattens all fetched pages into a single list of items, renders them as cards, and shows a **"Load More"** button that calls `fetchNextPage()` to append the next page while retaining existing items. Handles loading, error, and end-of-feed states.
- `src/App.tsx` — Wraps the app in `QueryClientProvider` and renders the `Feed`.
- `vite.config.ts` — Configured with `server.port: 5123`.

### How it works
- `useInfiniteQuery` is configured with `queryKey: ['feed']`, a `queryFn` that calls `fetchFeedPage(pageParam)`, an `initialPageParam` of `undefined` (first page), and `getNextPageParam` that reads `lastPage.nextCursor`.
- Clicking "Load More" fetches the next page; TanStack Query appends it to `data.pages`, and the component flattens all pages so existing items are retained.
- The mock API serves 6 distinct pages of 10 items each, providing ample pagination testing.
