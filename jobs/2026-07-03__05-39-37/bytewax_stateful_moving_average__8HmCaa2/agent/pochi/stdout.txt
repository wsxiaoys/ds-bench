## How it works

The dataflow (`flow`) is composed of these steps:

1. **`op.input` + `FileSource("input.csv")`** — reads raw `sensor_id,temperature` lines.
2. **`op.filter`** — skips blank lines (e.g. a trailing newline at EOF).
3. **`op.map("parse", ...)`** — splits each line into `(sensor_id, float(temperature))`, keeping keys as strings.
4. **`op.key_on("key_on_sensor", ...)`** — keys the stream by `sensor_id` so state is tracked per sensor.
5. **`op.stateful_map("moving_average", ...)`** — the core stateful step. The mapper keeps a `deque(maxlen=3)` of recent temperatures per sensor and returns the average of the available readings (1, 2, or 3). A **brand-new deque is constructed on every call** (`deque(state, maxlen=...)` then `.append`), so the previous state object is never mutated in place — keeping it compatible with Bytewax's recovery snapshots.
6. **`op.map("format", ...)`** — turns each keyed `(sensor_id, average)` into `(sensor_id, "sensor_id,average:.2f")` so the value is the full CSV line while the key remains for the sink's partition routing.
7. **`op.output` + `FileSink("output.csv")`** — writes one formatted line per input line.
