## What was done

**Created `/home/user/myproject/optimistic.js`** which:

1. **Reads the current document** (id=1) to capture its `version`.
2. **Simulates a concurrent/conflicting update** inside an interactive `$transaction`: it attempts an `updateMany` conditioned on a *stale* version (`currentVersion - 1`). Because the actual row's version is newer, zero rows match, so the handler throws `Version mismatch - optimistic concurrency conflict`, rolling the transaction back. This is caught and recorded as `conflictCaught: true`.
3. **Performs a valid update** with the *correct* version inside another interactive `$transaction`, re-reading the row, asserting `version === expectedVersion`, then updating `content: 'Updated'` and `version: { increment: 1 }`.
4. **Writes the result** to `/home/user/myproject/optimistic_result.json`.
