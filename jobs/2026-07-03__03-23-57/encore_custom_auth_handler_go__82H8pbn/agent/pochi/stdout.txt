In this task, you will create an Encore Go application that implements a custom authentication handler and a protected API endpoint, and then deploy it to Encore Cloud. ## Requirements - Create an Encore Go app with two packages: `auth` and `dashboard`. - In the `auth` package, implement an authentication handler that validates an incoming token. - The auth handler should accept a token.
