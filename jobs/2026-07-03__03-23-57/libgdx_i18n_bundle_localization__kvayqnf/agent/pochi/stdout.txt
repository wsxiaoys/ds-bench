# libGDX Headless: I18NBundle Localization Console ## Background libGDX ships an internationalization helper, `com.badlogic.gdx.utils.I18NBundle`, that loads a family of `.properties` files (a base file plus one per locale) and resolves keys for the active locale, falling back to the base bundle when a key is missing for the requested locale. Bundles are loaded from a `FileHandle` (typically `Gdx.files.internal("i18n/Messages")`), which makes the feature easy to drive under the non-rendering **headless** backend (`com.badlogicgames.gdx:gdx-backend-headless`) because no GPU, audio, or input plumbing is involved. In this task you will build a libGDX 1.14.2 project that boots a `HeadlessApplication`, ships a small family of localized resource bundles, and exposes a command-driven console that: 1. Switches between locales on demand. 2. Looks up plain keys with `bundle.get(...)`. 3. Formats parameterized keys with `bundle.format(...)`. 4. Demonstrates locale-to-base fallback for missing keys. 5. Reports a useful error to stderr (and exits non-zero) when the command file is malformed. ## Requirements * Create a Gradle (Java 17) project at `/home/user/gdx-game` that depends on libGDX `1.14.2` (`gdx`, `gdx-backend-headless`, `gdx-platform:natives-desktop`). * Implement a libGDX `ApplicationListener` (or `ApplicationAdapter`) that boots under `com.badlogic.gdx.backends.headless.HeadlessApplication`. * Provide three properties files under the project's `assets/i18n/` directory and load them via `Gdx.files.internal("i18n/Messages")`: * `assets/i18n/Messages.properties` (base / English content): ``` greeting=Hello farewell=Goodbye welcomeUser=Welcome, {0}! scoreReport=Player {0} scored {1} points gameName=Cosmic Quest ``` * `assets/i18n/Messages_fr.properties` (French; intentionally **omits** `gameName` to exercise base-bundle fallback): ``` greeting=Bonjour farewell=Au revoir welcomeUser=Bienvenue, {0} ! scoreReport=Le joueur {0} a marque {1} points ``` * `assets/i18n/Messages_de.properties` (German; also omits `gameName`): ``` greeting=Hallo farewell=Auf Wiedersehen welcomeUser=Willkommen, {0}! scoreReport=Spieler {0} hat {1} Punkte erzielt ``` Files must be UTF-8 encoded (the default for `I18NBundle.createBundle`). * Produce a runnable launcher (via the Gradle `application` plugin) at `/home/user/gdx-game/build/install/gdx-game/bin/gdx-game` that accepts a single `--input=` argument naming a command file and drives the headless app to completion. * Bundles must be loaded for each locale via `I18NBundle.createBundle(Gdx.files.internal("i18n/Messages"), new java.util.Locale(<code>))`.
