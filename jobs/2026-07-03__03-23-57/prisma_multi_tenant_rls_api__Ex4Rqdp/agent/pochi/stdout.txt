I have built a multi-tenant REST API with Express and Prisma Client, enforcing tenant isolation using a Prisma Client Extension based on the `x-tenant-id` header.

### Key Components Built

1. **Database Schema (`prisma/schema.prisma`)**:
   - Defined the `Item` model containing `id`, `name`, and `tenantId` fields.
   - Set up SQLite as the database provider.

2. **Prisma Configuration (`prisma.config.ts`)**:
   - Configured the SQLite connection URL from the environment variable (`DATABASE_URL`).

3. **Prisma 7 Driver Adapter Integration**:
   - Installed `@prisma/adapter-better-sqlite3` and `better-sqlite3` to comply with Prisma 7's architecture requiring pluggable driver adapters for SQLite.

4. **Multi-Tenant Server (`server.js`)**:
   - Initialized `PrismaClient` with the `PrismaBetterSqlite3` driver adapter.
   - Built an Express middleware that checks for the `x-tenant-id` header (returning `400 Bad Request` if missing).
   - Created a scoped Prisma Client per request using `prisma.$extends` to intercept `item` queries:
     - **Reads (`findMany`)**: Automatically appends `{ tenantId }` to the query's `where` clause.
     - **Writes (`create`)**: Automatically injects `{ tenantId }` into the created item's data.
   - Exposed REST endpoints:
     - `GET /items` — retrieves only items belonging to the current tenant.
     - `POST /items` — creates an item for the current tenant.

### How to Run the Server

To start the server, run:
```bash
node server.js
```

### Verification & Testing Examples

1. **Missing Tenant Header (Returns 400 Bad Request)**:
   ```bash
   curl -i -X GET http://localhost:3000/items
   ```
   *Response:*
   ```json
   {"error":"x-tenant-id header is required"}
   ```

2. **Create Item for Tenant 1**:
   ```bash
   curl -i -X POST -H "Content-Type: application/json" -H "x-tenant-id: tenant-1" -d '{"name": "Item A"}' http://localhost:3000/items
   ```
   *Response:*
   ```json
   {"id":1,"name":"Item A","tenantId":"tenant-1"}
   ```

3. **Create Item for Tenant 2**:
   ```bash
   curl -i -X POST -H "Content-Type: application/json" -H "x-tenant-id: tenant-2" -d '{"name": "Item B"}' http://localhost:3000/items
   ```
   *Response:*
   ```json
   {"id":2,"name":"Item B","tenantId":"tenant-2"}
   ```

4. **Retrieve Items for Tenant 1 (Isolated)**:
   ```bash
   curl -i -X GET -H "x-tenant-id: tenant-1" http://localhost:3000/items
   ```
   *Response:*
   ```json
   [{"id":1,"name":"Item A","tenantId":"tenant-1"}]
   ```
