For a metric with at least one stored sample, let `T` be the greatest `recordedAt` among that metric's stored samples, and define: - current window: samples with `T - 3600s < recordedAt <= T` - previous window: samples with `T - 7200s < recordedAt <= T - 3600s` and persist: - `count`: the number of samples in the current window. - `avg`: the arithmetic mean of the current-window values, rounded to 3 decimal places, half away from zero. - `p95`: the nearest-rank 95th percentile of the current-window values, i.e. sort the current-window values ascending and take the value whose 1-based position is `ceil(0.95 * count)`. - `delta`: `p95(current window) - p95(previous window)`, rounded to 3 decimal places, half away from zero, or `null` when the previous window contains no samples. 3. **Background Worker (`rollupMetrics`)**
   - Enqueued via PgBoss under the exact name `rollupMetrics`.

   - Computes rolling metrics:

     - **Previous Window**: `T - 7200s < recordedAt <= T - 3600s`
     - **Rounding**: Robust half-away-from-zero rounding to 3 decimal places for `avg` and `delta`.
     - **Percentile**: Nearest-rank 95th percentile using the `ceil(0.95 * count)` formula.
     - **Delta**: `p95(current window) - p95(previous window)`.
