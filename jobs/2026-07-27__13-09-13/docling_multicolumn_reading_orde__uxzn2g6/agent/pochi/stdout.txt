## `main.py`

The script parses `assets/report.pdf` using `docling` (fully offline via pre-baked model artifacts at `DOCLING_ARTIFACTS_PATH`) and reconstructs human reading order from layout provenance.

### Algorithm

1. **Parse** the PDF with `docling` to get all text items with their bounding boxes, labels, and content layers.
2. **Filter** out page furniture (headers, footers, page numbers) by checking `content_layer == FURNITURE` and `label` values.
3. **Convert** bounding boxes from docling's `BOTTOMLEFT` coordinate origin to top-left origin (`t_topleft = page_height - t_bottomleft`).
4. **Detect columns** per page by clustering the x-centers of non-spanning body elements. Elements spanning >65% of page width are classified as full-width spanning elements.
5. **Assign columns** by matching each element's x-center to the nearest column cluster center.
6. **Order elements**: spanning elements first (top-to-bottom), then each column left-to-right (top-to-bottom within each column).
7. **Handle multi-prov items**: items with multiple provenance entries (text split across columns) are treated as separate columnar elements, one per bbox.

### Outputs

- **`output/pages.json`** — Machine-readable per-page description with `page_no`, `column_count`, and `elements` (each with `id`, `column`, `bbox`).
- **`output/reading_order.txt`** — Linearized plain-text rendering in true reading order.
